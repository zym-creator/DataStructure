# 6. 数组实现的队列

> 对应源码：`code/6_队列的数组实现.cpp`

## 1. 队列的特点

队列（Queue）遵守“先进先出”（FIFO）：

```text
入队：3 -> 5 -> 11
出队：3 -> 5 -> 11
```

## 2. 循环数组

程序使用循环数组，避免只因为队头向后移动就浪费前面的空间。

```cpp
ElementType data_[MaxSize]{};
int front_ = 0; // 队头下标
int rear_ = 0;  // 下一个可插入位置
int size_ = 0;  // 当前元素数量
```

`rear_` 到达数组末尾后，通过下式回到第一个位置：

```cpp
rear_ = (rear_ + 1) % MaxSize;
```

## 3. 入队和出队

### `Enqueue`

1. 判断是否满队列。
2. 把值放到 `data_[rear_]`。
3. 移动 `rear_`。
4. 将 `size_` 加一。

### `Dequeue`

1. 判断是否空队列。
2. 读取 `data_[front_]`。
3. 移动 `front_`。
4. 将 `size_` 减一。

## 4. 为什么需要 `size_`

当 `front_ == rear_` 时，可能是空队列，也可能是循环一圈后的状态。使用 `size_` 可以清楚区分：

- `size_ == 0`：空队列。
- `size_ == MaxSize`：满队列。

## 5. 复杂度

| 操作 | 复杂度 |
| --- | --- |
| `Enqueue` | `O(1)` |
| `Dequeue` | `O(1)` |
| `IsEmpty` / `IsFull` | `O(1)` |

## 6. 优缺点

- 入队和出队都很快。
- 不需要 `new` 和 `delete`。
- 容量固定为 `100`，满了后不能继续入队。
