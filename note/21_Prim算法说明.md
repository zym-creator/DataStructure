# 21. Prim 算法

> 对应源码：`code/21_Prim.cpp`

## 1. 最小生成树

对一张连通无向带权图，生成树包含所有 `V` 个顶点、恰好 `V-1` 条边，并且没有环。所有生成树中边权总和最小的一棵称为最小生成树（MST）。

Prim 算法从一个顶点开始，不断将当前生成树向外扩展。

## 2. 切分与贪心选择

搜索过程中，顶点被分为两组：

```text
已收录顶点：已经在生成树中
未收录顶点：还在树外
```

Prim 每次选择一条跨越这两组顶点的最小权边。根据最小生成树的切分性质，这条边可以安全加入 MST。

## 3. 邻接表与候选边

图使用标准容器邻接表：

```cpp
std::vector<std::vector<Edge>> adjacency_;
```

最小堆中保存从已收录区域通向外部的候选边：

```cpp
struct Candidate {
    Vertex from;
    Vertex to;
    WeightType weight;
};
```

`std::priority_queue` 通过比较器让权重最小的边位于队首。

## 4. 算法步骤

1. 选择起点，将其标记为已收录。
2. 把起点通向未收录顶点的边放入最小堆。
3. 取出权重最小的候选边。
4. 如果边的终点已被收录，丢弃这条过期边。
5. 否则收录该顶点和边，并将新顶点的出边加入堆。
6. 得到 `V-1` 条边时完成。

同一顶点可能被多条候选边指向。因此边出堆时必须检查：

```cpp
if (collected[candidate.to]) {
    continue;
}
```

## 5. 不连通图

如果堆已经为空，结果中却不足 `V-1` 条边，说明从起点无法到达所有顶点。该图不存在覆盖所有顶点的生成树。

如果需要处理不连通图，可以对每个连通分量分别运行 Prim，得到最小生成森林。

## 6. 负权和零权边

最小生成树不是最短路径问题，Prim 可以正常处理负权边和零权边。重构版不再用 `0` 表示“没有边”，所以权重为零的边不会被忽略。

## 7. 复杂度

使用邻接表和二叉堆：

| 资源 | 复杂度 |
| --- | --- |
| 时间 | `O(E log E)`，常写为 `O(E log V)` |
| 图的空间 | `O(V+E)` |
| 候选堆 | `O(E)` 最坏 |

## 8. 与原实现的区别

原代码使用固定邻接矩阵和线性扫描寻找下一个顶点，并将 `dist=0` 同时当作已收录标记，导致零权边语义混淆。输出循环还会访问 `MST[Nv]` 越界。

重构版将已收录状态、候选边和结果明确分开，并在输出前验证图是否连通。
