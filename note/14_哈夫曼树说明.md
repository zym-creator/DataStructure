# 14. 哈夫曼树

> 对应源码：`code/14_哈夫曼树.cpp`

## 1. 什么是哈夫曼树

给定 `n` 个权值，将它们作为二叉树的叶子节点。叶子的带权路径长度是：

```text
权值 × 从根到该叶子的边数
```

整棵树的带权路径长度（Weighted Path Length，WPL）为：

```text
WPL = Σ(叶子权值 × 叶子深度)
```

哈夫曼树是所有叶子权值相同的二叉树中 WPL 最小的树，因此也称为最优二叉树。

## 2. 构建方法

哈夫曼树采用贪心思想构建：

1. 将每个权值分别创建为一棵只有根节点的树。
2. 从所有树中取出根权值最小的两棵。
3. 创建新的父节点，权值为两个孩子权值之和。
4. 将新树放回候选集合。
5. 重复以上过程，直到只剩一棵树。

例如权值为 `1、4、7、13`：

```text
第一次：1 + 4 = 5       候选：5、7、13
第二次：5 + 7 = 12      候选：12、13
第三次：12 + 13 = 25    候选：25
```

得到：

```text
          25
         /  \
       12    13
      /  \
     5    7
    / \
   1   4
```

权值越小的叶子越可能位于深层，权值越大的叶子越接近根，从而降低 WPL。

## 3. 树节点

每个节点保存权值和两个孩子指针：

```cpp
struct Node {
    WeightType weight;
    int order;
    Node* left;
    Node* right;
};
```

- 叶子节点的 `left` 和 `right` 都为 `nullptr`。
- 非叶节点的权值是左右孩子权值之和。
- `order` 记录节点的创建顺序，用来稳定处理相同权值。

`order` 不是哈夫曼树的必要数据，也不影响 WPL。它只使示例在不同编译器上产生相同的树形。

## 4. 使用 `std::priority_queue`

构建过程需要反复取出最小权值，适合使用最小堆。C++ 的 `std::priority_queue` 默认是最大堆，因此需要自定义比较器：

```cpp
struct CompareNode {
    bool operator()(const Node* first, const Node* second) const {
        if (first->weight != second->weight) {
            return first->weight > second->weight;
        }
        return first->order > second->order;
    }
};
```

定义最小堆：

```cpp
std::priority_queue<Node*, std::vector<Node*>, CompareNode> minHeap;
```

三个模板参数分别是：

| 参数 | 含义 |
| --- | --- |
| `Node*` | 堆中存储的元素类型 |
| `std::vector<Node*>` | 堆的底层容器 |
| `CompareNode` | 决定哪个节点优先出堆 |

比较器中使用 `>` 表示较大权值的优先级更低，因此 `top()` 返回最小权值节点。

## 5. 为什么每次取最小的两个

每次合并两棵树后，这两棵树中的所有叶子都会向下增加一层。因此，这次合并会让 WPL 增加：

```text
第一棵树的总权值 + 第二棵树的总权值
```

让当前最小的两个总权值承担这次深度增加，会使累计代价最小。重复执行这个局部最优选择，最终得到全局最小的 WPL。

另一个实用结论是：

```text
哈夫曼树的 WPL = 构建过程中每次合并权值之和
```

## 6. WPL 的计算

代码递归遍历树，只在叶子处累加权值：

```cpp
if (node->left == nullptr && node->right == nullptr) {
    return static_cast<long long>(node->weight) * depth;
}

return CalculateWPL(node->left, depth + 1) +
       CalculateWPL(node->right, depth + 1);
```

中间节点的权值只用于建树，不能直接加入 WPL。

## 7. 复杂度

初始时向堆中插入 `n` 个节点，后续进行 `n - 1` 次合并。每次合并包含两次出堆和一次入堆，每个堆操作为 `O(log n)`。

| 操作 | 时间复杂度 |
| --- | --- |
| 构建哈夫曼树 | `O(n log n)` |
| 遍历哈夫曼树 | `O(n)` |
| 计算 WPL | `O(n)` |

哈夫曼树共有 `n` 个叶子和 `n - 1` 个内部节点，总节点数为 `2n - 1`，因此空间复杂度是 `O(n)`。

## 8. 内存管理

`HuffmanTree` 对象拥有整棵树。构建完成后，`root_` 指向根节点；析构函数通过后序遍历依次删除左右子树和当前节点。

```cpp
Destroy(node->left);
Destroy(node->right);
delete node;
```

优先队列只保存 `Node*`，不拥有树节点。节点的最终所有权归 `HuffmanTree`，避免了重复释放。

## 9. 与原实现的区别

原代码使用 `malloc` 创建 C 风格的堆和树，且没有完整释放动态内存。重构后：

- 使用 `HuffmanTree` 类表达树的所有权。
- 使用 `new` / `delete` 与构造、析构函数管理节点。
- 使用 `std::priority_queue` 代替手写堆，将学习重点放在哈夫曼树的合并策略上。
- 取消哨兵值，没有“输入必须大于某个常量”的隐含限制。
