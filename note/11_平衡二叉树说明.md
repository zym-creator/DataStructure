# 11. 平衡二叉树（AVL 树）

> 对应源码：`code/11_平衡二叉树.cpp`

## 1. 为什么需要平衡

二叉搜索树的左子树值更小，右子树值更大，因此能按大小快速查找。但若依次插入 `1、2、3、4`，树会退化成链表，查找、插入和删除都会变成 `O(n)`。

AVL 树是一种平衡二叉搜索树。它要求每个节点的左右子树高度之差最多为 `1`，使树高始终维持在 `O(log n)`。

## 2. 节点高度与平衡因子

每个节点额外保存 `height`：

```cpp
struct Node {
    ElementType data;
    int height;
    Node* left;
    Node* right;
};
```

空树高度为 `0`，叶子节点高度为 `1`。

平衡因子定义为：

```text
平衡因子 = 左子树高度 - 右子树高度
```

- 平衡因子为 `-1`、`0`、`1`：节点平衡。
- 平衡因子大于 `1`：左子树过高。
- 平衡因子小于 `-1`：右子树过高。

## 3. 四种旋转

插入或删除后，从变化路径向上更新高度；发现失衡就旋转。

| 失衡类型 | 产生原因 | 调整方式 |
| --- | --- | --- |
| LL | 插入到左孩子的左侧 | 对当前节点右旋 |
| RR | 插入到右孩子的右侧 | 对当前节点左旋 |
| LR | 插入到左孩子的右侧 | 先左旋左孩子，再右旋当前节点 |
| RL | 插入到右孩子的左侧 | 先右旋右孩子，再左旋当前节点 |

例如 LL 型：

```text
      30                 20
     /                  /  \
    20       右旋      10   30
   /
  10
```

`RotateRight` 中，原根节点 `30` 变成 `20` 的右孩子；`20` 原先的右子树接到 `30` 的左侧。旋转后必须先更新较低节点的高度，再更新新根高度。

## 4. 插入

插入过程与普通二叉搜索树相同：小值进入左子树，大值进入右子树，重复值不插入。

递归返回时调用 `Balance`：

```cpp
node->left = InsertNode(node->left, value);
return Balance(node);
```

这样每一层祖先节点都会重新计算高度，并在需要时完成旋转。由于旋转次数有限，插入仍是 `O(log n)`。

## 5. 删除

删除节点的规则与二叉搜索树一致：

1. 没有孩子：直接删除。
2. 只有一个孩子：让孩子接替当前节点。
3. 有两个孩子：用右子树最小值（中序后继）覆盖当前值，再删除后继。

删除会降低某个子树高度，因此递归返回时也必须调用 `Balance`。与插入不同，删除可能使多层祖先连续失衡，但每层最多进行一次单旋或双旋。

## 6. 复杂度

AVL 树的高度始终是 `O(log n)`：

| 操作 | 时间复杂度 |
| --- | --- |
| 查找 | `O(log n)` |
| 插入 | `O(log n)` |
| 删除 | `O(log n)` |
| 中序遍历 | `O(n)` |

每个节点多保存一个 `int height`，额外空间为 `O(n)`。

## 7. 适用场景

AVL 树适合读操作频繁、又要求键值保持有序的内存数据，例如有序集合、按范围检索的数据和实时排行榜。与普通二叉搜索树相比，它通过维护平衡换取稳定的查询性能。
