# 17. 图的邻接表实现

> 对应源码：`code/17_图的邻接表实现.cpp`

## 1. 邻接表

邻接表为每个顶点建立一条链表，链表只保存与该顶点相邻的顶点。

例如无向图包含边：

```text
0-1，0-3，1-2
```

邻接表可以表示为：

```text
0 -> 3 -> 1
1 -> 2 -> 0
2 -> 1
3 -> 0
```

与邻接矩阵不同，不存在的边不占用链表节点。

## 2. 表头数组和边节点

源码使用动态数组保存每条链表的头指针：

```cpp
EdgeNode** heads_;
```

`heads_[v]` 指向顶点 `v` 的第一个邻接节点。如果 `v` 没有邻接顶点，它就是 `nullptr`。

每个边节点保存：

```cpp
struct EdgeNode {
    Vertex adjacent;
    WeightType weight;
    EdgeNode* next;
};
```

- `adjacent`：邻接顶点的下标。
- `weight`：边的权重。
- `next`：同一顶点的下一条边。

## 3. 无向边需要两个节点

无向边 `first-second` 表示两个方向的相邻关系，因此需要创建两个链表节点：

```cpp
heads_[first] = new EdgeNode{second, weight, heads_[first]};
heads_[second] = new EdgeNode{first, weight, heads_[second]};
```

例如插入 `0-3`：

```text
heads_[0] -> 3
heads_[3] -> 0
```

这里使用的是链表头插法，新边会出现在邻接表最前面，因此打印顺序通常与输入顺序相反。

虽然一条无向边占用两个 `EdgeNode`，`edgeCount_` 仍然只增加 `1`。

## 4. 插入和更新边

`AddEdge` 先检查顶点范围、自环和负权。然后在 `first` 的链表中寻找 `second`：

```cpp
EdgeNode* firstEdge = FindEdge(first, second);
```

如果边已经存在，同时更新两个方向的权重；如果不存在，才创建两个新节点。这可以避免同一条边在链表中重复出现。

在顶点 `v` 的链表中寻找邻接顶点需要最多遍历 `degree(v)` 个节点：

```text
O(degree(v))
```

## 5. 删除边

删链表节点时需要记住当前节点和前一个节点：

```cpp
EdgeNode* current = heads_[from];
EdgeNode* previous = nullptr;
```

找到目标后分两种情况：

- `previous == nullptr`：删除的是链表第一个节点，需要修改 `heads_[from]`。
- `previous != nullptr`：让前一个节点跨过当前节点。

删除无向边需要同时删除 `first -> second` 和 `second -> first` 两个节点。

## 6. 度数和遍历

无向图中，顶点的度是与它相连的边数。在邻接表中，它正好等于对应链表的长度。

```cpp
for (const EdgeNode* edge = heads_[vertex];
     edge != nullptr;
     edge = edge->next) {
    ++degree;
}
```

计算一个顶点的度需要 `O(degree(v))`。遍历全部邻接表时，每个顶点访问一次，每条无向边节点访问两次，因此是 `O(V + E)`。

## 7. 复杂度

| 操作 | 时间复杂度 |
| --- | --- |
| 查询边 `u-v` | `O(degree(u))` |
| 插入不重复的边 | `O(degree(u))` |
| 删除边 | `O(degree(u) + degree(v))` |
| 遍历顶点 `v` 的邻接点 | `O(degree(v))` |
| 遍历整个图 | `O(V + E)` |

表头数组需要 `O(V)` 空间，无向边节点需要 `O(2E)` 空间，忽略常数后总空间复杂度为 `O(V + E)`。

邻接表适合边数远小于 `V²` 的稀疏图。

## 8. 内存释放

每次插入新边都会使用 `new` 创建链表节点。析构时，`Clear` 逐条遍历所有链表：

```cpp
while (current != nullptr) {
    EdgeNode* nodeToDelete = current;
    current = current->next;
    delete nodeToDelete;
}
```

最后再使用 `delete[] heads_` 释放表头数组。表头数组和链表节点是两类不同的动态内存，必须分别释放。

## 9. 与邻接矩阵对比

| 特点 | 邻接矩阵 | 邻接表 |
| --- | --- | --- |
| 空间 | `O(V²)` | `O(V + E)` |
| 查询两点是否相邻 | `O(1)` | `O(degree(v))` |
| 遍历某顶点的邻接点 | `O(V)` | `O(degree(v))` |
| 适合 | 稠密图 | 稀疏图 |

两种实现使用相同的顶点编号、无向边和非负权重约定，可以用同一组输入对比它们的存储结果。

## 10. 与原实现的区别

原代码使用全局的固定长度数组和 `malloc`，且没有释放表头和边节点。重构版根据实际顶点数分配表头数组，将所有操作封装在类中，并在析构时完整释放链表。
