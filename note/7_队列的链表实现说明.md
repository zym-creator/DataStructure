# 7. 链表实现的队列

> 对应源码：`code/7_队列的链表实现.cpp`

## 1. 基本结构

队列遵守先进先出。链式队列用两个指针分别指向队头和队尾：

```text
front_ -> [5 | next] -> [4 | next] -> [3 | nullptr] <- rear_
```

- `front_` 指向下一个出队的节点。
- `rear_` 指向最后一个节点，新元素从这里连接。
- 空队列时，`front_` 和 `rear_` 都是 `nullptr`。

## 2. 入队 `Enqueue`

1. 用 `new` 创建新节点。
2. 如果是空队列，让 `front_` 和 `rear_` 都指向新节点。
3. 如果不是空队列，让原来的 `rear_->next` 指向新节点，再移动 `rear_`。

```cpp
Node* newNode = new Node{value, nullptr};

if (rear_ == nullptr) {
    front_ = newNode;
    rear_ = newNode;
} else {
    rear_->next = newNode;
    rear_ = newNode;
}
```

## 3. 出队 `Dequeue`

1. 判断是否空队列。
2. 保存 `front_` 节点。
3. 读取节点数据，并让 `front_` 指向下一个节点。
4. 如果出队后队列变空，还要让 `rear_ = nullptr`。
5. 用 `delete` 释放原节点。

## 4. 内存管理

每次入队都用 `new` 创建节点，每次出队都用 `delete` 释放节点。析构函数调用 `Clear()`，确保对象销毁前清理所有节点。

## 5. 复杂度

| 操作 | 复杂度 |
| --- | --- |
| `Enqueue` | `O(1)` |
| `Dequeue` | `O(1)` |
| `IsEmpty` | `O(1)` |
| `Clear` | `O(n)` |

## 6. 数组队列与链式队列

| 特性 | 数组队列 | 链式队列 |
| --- | --- | --- |
| 容量 | 固定 | 按需创建 |
| 入队 | `O(1)` | `O(1)` |
| 出队 | `O(1)` | `O(1)` |
| 额外空间 | 不需指针 | 每个节点需 `next` |
| 内存管理 | 简单 | 需要 `new/delete` |
