# 16. 图的邻接矩阵实现

> 对应源码：`code/16_图的邻接矩阵实现.cpp`

## 1. 邻接矩阵

假设图有 `V` 个顶点，邻接矩阵使用一个 `V × V` 的表格表示顶点关系：

```text
matrix[i][j] = 边 i-j 的权重
```

例如无向边 `0-1` 的权重是 `2`：

```text
matrix[0][1] = 2
matrix[1][0] = 2
```

因为无向边没有方向，邻接矩阵沿主对角线对称。

## 2. 用一维动态数组存储

源码使用：

```cpp
WeightType* matrix_;
```

构造时申请 `V × V` 个连续位置：

```cpp
new WeightType[vertexCount * vertexCount]
```

二维坐标 `(row, column)` 映射到一维下标：

```cpp
int Index(Vertex row, Vertex column) const {
    return row * vertexCount_ + column;
}
```

例如 `V = 5`，位置 `(2, 3)` 对应：

```text
2 × 5 + 3 = 13
```

这与真正的二维数组一样按行连续存储，但容量可以在运行时根据顶点数决定。

## 3. “没有边”与权重 0

如果直接用 `0` 表示没有边，就无法保存权重真的为 `0` 的边。源码规定边权非负，因此使用：

```cpp
static constexpr WeightType NoEdge = -1;
```

表示两个不同顶点之间没有边。主对角线上的值初始化为 `0`，表示顶点到自身的距离为零。

打印时使用 `-` 显示 `NoEdge`，所以输出中的数字 `0` 仍然可以表示真实的零权边。

## 4. 插入边

```cpp
bool AddEdge(Vertex first, Vertex second, WeightType weight)
```

插入前检查：

- 两个顶点都在 `[0, V-1]` 范围内。
- 两个顶点不同，本示例不接受自环。
- 权重非负。

无向边需要写入两个对称位置：

```cpp
matrix_[Index(first, second)] = weight;
matrix_[Index(second, first)] = weight;
```

如果边已经存在，`AddEdge` 只更新权重，不会重复增加 `edgeCount_`。

## 5. 删除和查询

删除边就是将两个对称位置恢复为 `NoEdge`：

```cpp
matrix_[Index(first, second)] = NoEdge;
matrix_[Index(second, first)] = NoEdge;
```

`HasEdge` 只需访问一个数组位置，因此为 `O(1)`。`GetWeight` 也为 `O(1)`。

计算顶点的度需要扫描对应的一整行：

```text
Degree(v) = 第 v 行中存在的边数
```

所以时间复杂度为 `O(V)`。

## 6. 复杂度

| 操作 | 时间复杂度 |
| --- | --- |
| 插入边 | `O(1)` |
| 删除边 | `O(1)` |
| 查询两点是否相邻 | `O(1)` |
| 查询边权 | `O(1)` |
| 计算一个顶点的度 | `O(V)` |
| 遍历整个矩阵 | `O(V²)` |

无论图中实际有多少条边，邻接矩阵都需要 `O(V²)` 空间。因此它适合边较多的稠密图，或需要频繁查询两点是否相邻的场景。

## 7. 内存管理

构造函数使用 `new[]` 申请矩阵，析构函数使用 `delete[]` 释放。类禁用默认拷贝，避免两个对象共用同一个矩阵并重复释放。

## 8. 与原实现的区别

原代码使用全局 `100 × 100` 数组，即使只有几个顶点也会占用全部空间，且将 `0` 同时用作“无边”和边权。重构版根据实际顶点数分配空间，并将无边状态与零权边分开。
