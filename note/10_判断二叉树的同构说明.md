# 10. 判断二叉树的同构

> 对应源码：`code/10_判断二叉树的同构.cpp`

## 1. 什么是同构

如果一棵二叉树可以通过交换某些节点的左右子树，变成另一棵二叉树，并且对应节点的值也相同，就说两棵树同构。

例如：

```text
第一棵树              第二棵树

      1                       1
     / \                     / \
    2   3                   3   2
   /     \                 /     \
  4       5               5       4
```

将第一棵树根节点的左右子树交换，再在子树中进行相应交换，就能得到第二棵树，所以它们同构。

## 2. 判断顺序

对两个当前节点 `first` 和 `second` 进行判断：

1. 两个节点都为空：这部分同构，返回 `true`。
2. 只有一个节点为空：结构不同，返回 `false`。
3. 两个节点的值不同：返回 `false`。
4. 对比“不交换左右子树”的情况。
5. 对比“交换左右子树”的情况。
6. 只要两种情况中有一种成立，就返回 `true`。

## 3. 不交换的情况

```cpp
bool noSwap = AreIsomorphic(first->left, second->left)
           && AreIsomorphic(first->right, second->right);
```

分别将第一棵树的左子树与第二棵树的左子树对比，右子树与右子树对比。

## 4. 交换的情况

```cpp
bool withSwap = AreIsomorphic(first->left, second->right)
             && AreIsomorphic(first->right, second->left);
```

将第一棵树的左子树与第二棵树的右子树对比，右子树与左子树对比。

最后：

```cpp
return noSwap || withSwap;
```

`||` 表示逻辑或，只要一种方式成功，就认为当前两棵子树同构。

## 5. 为什么要递归

一棵二叉树由根节点、左子树和右子树组成。左右子树本身又是二叉树，所以可以继续使用相同的判断函数。

## 6. 复杂度

这个直接写法在节点值大量重复时，可能同时尝试“交换”和“不交换”两种分支，最坏情况下递归次数会明显增多。

对学习阶段的一般二叉树，可以先重点理解它的递归判断思路和空节点边界条件。

## 7. 内存管理

`BinaryTree` 析构时使用后序方式释放所有节点：先释放左子树，再释放右子树，最后 `delete` 当前节点。
