# 4. 栈存储的线性表

> 对应源码：`code/4_栈存储的线性表.cpp`

## 1. 栈的特点

栈（Stack）遵守“后进先出”（LIFO）：

```text
入栈：5 -> 7 -> 66
出栈：66 -> 7 -> 5
```

可以把栈想象成一叠盘子，只能从最上面放入和取出。

## 2. 数组存储

```cpp
static constexpr int MaxSize = 100;
ElementType data_[MaxSize]{};
int top_ = -1;
```

- `data_` 保存元素。
- `MaxSize` 是栈的最大容量。
- `top_` 是栈顶元素的下标。
- 空栈时 `top_ == -1`，满栈时 `top_ == MaxSize - 1`。

## 3. 入栈和出栈

### 入栈 `Push`

1. 先判断是否满栈。
2. 让 `top_` 加一。
3. 把值写入 `data_[top_]`。

```cpp
bool Push(ElementType value) {
    if (IsFull()) {
        return false;
    }

    ++top_;
    data_[top_] = value;
    return true;
}
```

### 出栈 `Pop`

1. 先判断是否空栈。
2. 读取 `data_[top_]`。
3. 让 `top_` 减一。

```cpp
bool Pop(ElementType& value) {
    if (IsEmpty()) {
        return false;
    }

    value = data_[top_];
    --top_;
    return true;
}
```

`bool` 用来表示操作是否成功，`value` 用来返回出栈的数据。这样可以避免空栈时返回无效值。

## 4. 后缀表达式

普通表达式：

```text
2 + 3
```

后缀表达式把运算符写在操作数后面：

```text
2 3 +
```

它不需要括号，适合用栈求值。

### 求值步骤

1. 从左到右读取。
2. 遇到数字就入栈。
3. 遇到运算符，先出栈右操作数，再出栈左操作数。
4. 计算后把结果重新入栈。
5. 读完后如果只剩一个数，它就是结果。

## 5. 代码中的例子

```cpp
const char* expression = "2 3 + 4 * 5 -";
int answer = 0;

if (EvaluatePostfix(expression, answer)) {
    std::cout << answer << '\\n';
}
```

计算过程：

```text
2 3 + 4 * 5 -
2 3 +       -> 5
5 4 *       -> 20
20 5 -      -> 15
```

当前实现支持多位整数、负数以及 `+`、`-`、`*`、`/`，数字之间应使用空格分隔，例如 `12 3 +`。

## 6. 错误检查

`EvaluatePostfix` 会检查：

- 运算符是否缺少操作数。
- 是否包含无效字符。
- 是否出现除以零。
- 读完后栈中是否恰好剩一个结果。

## 7. 复杂度

- `Push` 、`Pop` 、`IsEmpty` 、`IsFull` 和 `Size` 的时间复杂度都是 `O(1)`。
- 后缀表达式求值只需要扫描一次，时间复杂度是 `O(n)`。
- 求值时栈需要保存中间结果，额外空间复杂度是 `O(n)`。
