# 4. 栈存储的线性表

> 对应源码：`code/4_栈存储的线性表.cpp`

## 1. 什么是栈

栈（Stack）是一种只允许在一端进行操作的线性结构。这一端叫“栈顶”。

栈遵守 **后进先出**（LIFO，Last In First Out）：

```text
先入栈：5 -> 7 -> 66
出栈顺序：66 -> 7 -> 5
```

可以把栈想象成一叠盘子：只能从最上面放入和取出。

## 2. 数组存储

本程序使用固定大小的内置数组保存栈元素：

```cpp
static constexpr int MaxSize = 100;
ElementType data_[MaxSize]{};
int top_ = -1;
```

- `data_` 是真正保存元素的数组。
- `MaxSize` 表示栈的最大容量。
- `top_` 表示栈顶元素的下标。
- 刚创建时栈为空，没有栈顶元素，所以 `top_ = -1` 。

### `top_` 的变化

| 状态 | `top_` | 说明 |
| --- | ---: | --- |
| 空栈 | `-1` | 没有任何元素 |
| 有一个元素 | `0` | 栈顶是 `data_[0]` |
| 有两个元素 | `1` | 栈顶是 `data_[1]` |
| 装满 | `99` | 最后一个位置是 `data_[99]` |

## 3. 判断空和满

```cpp
bool IsEmpty() const {
    return top_ == -1;
}

bool IsFull() const {
    return top_ == MaxSize - 1;
}
```

- `top_ == -1` 说明没有元素，是空栈。
- `top_ == MaxSize - 1` 说明已经使用了最后一个位置，是满栈。

## 4. 入栈 `Push`

入栈就是把一个新元素放到栈顶：

1. 先判断是否满栈。
2. 让 `top_` 加一。
3. 把元素放入 `data_[top_]` 。

```cpp
bool Push(ElementType value) {
    if (IsFull()) {
        return false;
    }

    ++top_;
    data_[top_] = value;
    return true;
}
```

例如依次压入 `5` 、`7` 、`66` ：

```text
data_[0] = 5    top_ = 0
data_[1] = 7    top_ = 1
data_[2] = 66   top_ = 2
```

## 5. 出栈 `Pop`

出栈就是取出并删除栈顶元素：

1. 先判断是否空栈。
2. 读取 `data_[top_]` 。
3. 让 `top_` 减一。

```cpp
bool Pop(ElementType& value) {
    if (IsEmpty()) {
        return false;
    }

    value = data_[top_];
    --top_;
    return true;
}
```

`Pop` 使用返回值表示成功或失败，并使用引用参数 `value` 返回取出的数据：

```cpp
int value = 0;
if (stack.Pop(value)) {
    std::cout << value << '\n';
}
```

这比空栈时直接 `return` 一个未定义的值更安全。

## 6. `Size`：获取元素个数

```cpp
int Size() const {
    return top_ + 1;
}
```

因为空栈时 `top_` 是 `-1`，所以元素数量就是 `top_ + 1`。

## 7. 复杂度

| 操作 | 时间复杂度 | 原因 |
| --- | --- | --- |
| `IsEmpty` | `O(1)` | 只比较 `top_` |
| `IsFull` | `O(1)` | 只比较 `top_` |
| `Push` | `O(1)` | 直接操作栈顶 |
| `Pop` | `O(1)` | 直接操作栈顶 |
| `Size` | `O(1)` | 直接计算 |

## 8. 数组栈的性质

### 优点

- 实现简单，只需要数组和一个栈顶下标。
- 入栈和出栈都是 `O(1)`。
- 不需要 `new` 和 `delete`，不会因节点忘记释放而泄漏。

### 缺点

- 最大容量需要提前设定。
- 当栈满时无法继续入栈。

## 9. 应用场景

- 函数调用栈。
- 撤销和重做。
- 括号匹配。
- 深度优先搜索。
- 表达式计算。

## 10. 常见错误

- 没判断满栈就入栈，会访问数组边界之外。
- 没判断空栈就出栈，会读取无效数据。
- 把 `top_` 理解成元素个数；本程序中 `top_` 是栈顶下标，所以个数是 `top_ + 1`。
- 入栈和出栈顺序写反，记住栈遵守后进先出。
