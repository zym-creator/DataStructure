# 9. 二叉搜索树的操作

> 对应源码：`code/9_二叉搜索树的操作.cpp`

## 1. 二叉搜索树的性质

对每个节点来说：

- 左子树中所有值都小于当前节点。
- 右子树中所有值都大于当前节点。
- 本实现忽略重复值。

```text
        5
      /   \
     3     7
    / \   / \
   1   4 6   8
    \         \
     2         9
```

二叉搜索树的中序遍历结果一定是从小到大排列的。

## 2. 插入

1. 如果当前位置是空的，创建新节点。
2. 新值较小时，递归插入左子树。
3. 新值较大时，递归插入右子树。
4. 值相等时不做任何操作。

```cpp
if (value < node->data) {
    node->left = InsertNode(node->left, value);
} else if (value > node->data) {
    node->right = InsertNode(node->right, value);
}
```

## 3. 查找

查找不需要遍历整棵树：

- 目标值较小就进入左子树。
- 目标值较大就进入右子树。
- 相等时查找成功。
- 走到 `nullptr` 时表示没有找到。

## 4. 最小值和最大值

- 一直向左走，最后一个节点是最小值。
- 一直向右走，最后一个节点是最大值。

## 5. 删除节点

### 没有孩子

直接 `delete` 该节点，并返回 `nullptr`。

### 只有一个孩子

保存孩子地址，删除当前节点，再返回孩子。孩子会接替原节点的位置。

### 有两个孩子

1. 找到右子树中的最小节点，它叫中序后继。
2. 用后继的值覆盖当前节点。
3. 再从右子树中删除那个后继节点。

## 6. 为什么要接收新根

```cpp
root_ = DeleteNode(root_, value, deleted);
```

如果删除的正好是根节点，根可能会变成其孩子或后继。因此必须用 `root_` 接收 `DeleteNode` 返回的新地址。

## 7. 复杂度

令 `h` 表示树的高度：

| 操作 | 平均时间 | 最坏时间 |
| --- | --- | --- |
| 查找 | `O(log n)` | `O(n)` |
| 插入 | `O(log n)` | `O(n)` |
| 删除 | `O(log n)` | `O(n)` |
| 最小值/最大值 | `O(log n)` | `O(n)` |

当树比较平衡时，`h` 约为 `log n`。如果数据按顺序插入，树可能退化成类似链表的形状，此时 `h` 为 `n`。

## 8. 内存管理

每个节点都由 `new` 创建。删除节点时立即 `delete`，对象销毁时析构函数后序释放剩余的所有节点。
