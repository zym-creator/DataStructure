# 1. 复杂度与最大子列和

> 对应源码：`code/1_复杂度.cpp`

## 1. 什么是最大子列和

给定一个整数数组，从中选择一段连续元素，使这些元素的和尽可能大。

```text
数组：-2  11  -4  13  -5  -2
最大连续子列：11  -4  13
最大子列和：20
```

源码中将全部为负数时的结果设为 `0`，相当于允许选择空子列。

## 2. 什么是时间复杂度

时间复杂度表示：当输入规模 `n` 增大时，算法的计算量如何增长。它描述的是增长趋势，不是程序运行的精确秒数。

| 表示 | 含义 | 速度感受 |
| --- | --- | --- |
| `O(1)` | 计算量基本不变 | 非常快 |
| `O(n)` | 计算量随 `n` 成正比增长 | 通常可接受 |
| `O(n²)` | 常见于两层循环 | `n` 大时明显变慢 |
| `O(n³)` | 常见于三层循环 | `n` 稍大就很慢 |
| `O(n log n)` | 常见于分治 | 通常比 `O(n²)` 快 |

## 3. 源码中的五种方法

### 方法一：三层循环

枚举子列的开头和结尾，再用第三层循环对这段元素求和。它容易理解，但重复计算很多。

- 时间复杂度：`O(n³)`
- 额外空间复杂度：`O(1)`

### 方法二：边扩展边累加

确定开头后，向右扩展结尾并继续累加，不再从头计算相同区间的和。

- 时间复杂度：`O(n²)`
- 额外空间复杂度：`O(1)`

### 方法三：前缀和

`sum[i]` 保存从第 `0` 个元素到第 `i` 个元素的累加和。预处理后，可通过减去前面的部分得到子列和。

- 时间复杂度：`O(n²)`
- 额外空间复杂度：`O(n)`

### 方法四：分治

将数组从中间分成左右两部分，递归求出：

1. 左半部分的最大子列和。
2. 右半部分的最大子列和。
3. 跨越中点的最大子列和。
4. 返回三者中的最大值。

- 时间复杂度：`O(n log n)`
- 递归栈空间复杂度：`O(log n)`

### 方法五：在线处理

从左到右只扫描一次。如果当前累加和小于 `0`，它只会拖累后面的子列，因此将其重置为 `0`。

```cpp
tmpSum += a[i];

if (tmpSum < 0) {
    tmpSum = 0;
} else if (max < tmpSum) {
    max = tmpSum;
}
```

- 时间复杂度：`O(n)`
- 额外空间复杂度：`O(1)`

## 4. 五种方法对比

| 方法 | 核心思想 | 时间复杂度 | 额外空间 |
| --- | --- | --- | --- |
| 1 | 枚举首尾后重新求和 | `O(n³)` | `O(1)` |
| 2 | 固定首部，边扩展边累加 | `O(n²)` | `O(1)` |
| 3 | 前缀和 | `O(n²)` | `O(n)` |
| 4 | 分治与递归 | `O(n log n)` | `O(log n)` |
| 5 | 负和清零，一次扫描 | `O(n)` | `O(1)` |

## 5. 源码中需注意的问题

`main` 在各个 `MaxSubseqSum` 函数定义之前调用了它们，但文件开头没有函数声明。标准 C++ 编译器会报“未声明”错误。

修复方法有两种：

- 将所有函数定义移到 `main` 之前。
- 在 `main` 之前添加函数声明。

另外，当 `n == 0` 时，方法三会访问 `a[0]`，造成越界。输入规模应大于 `0`。

## 6. 学习重点

- 先通过循环层数理解 `O(n)`、`O(n²)` 和 `O(n³)`。
- 理解“避免重复计算”为什么能优化算法。
- 方法五最适合先掌握，分治法可在学习递归后再深入。
