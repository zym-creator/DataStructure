# 18. 图的迷宫遍历

> 对应源码：`code/18_图的迷宫遍历.cpp`

## 1. 题目与数据结构

给定一个迷宫，`1` 表示可通行，`0` 表示墙。从 `(0, 0)` 出发，求出迷宫中每个可达位置所需的最少步数。源代码允许八个方向走法，包括斜对角方向。

`Maze` 类使用两个动态数组：

```cpp
std::vector<std::string> grid_;       // 迷宫地图
std::vector<std::vector<int>> distance_; // 最少步数
```

BFS 队列中保存的是值类型坐标：

```cpp
struct Point {
    int row;
    int column;
};
```

不再为每个坐标使用 `malloc` 申请内存。

## 2. 为什么用 BFS

迷宫中每走一步代价都是 `1`。BFS 按距离分层访问：

```text
距离 0：起点
距离 1：起点一步可达的位置
距离 2：起点两步可达的位置
```

因此，一个位置第一次出队时，得到的就是它的最短距离。如果边的代价不都相同，就不能直接用这个 BFS 求最短路径，而应考虑 Dijkstra 或 A* 。

## 3. BFS 的初始化

`distance_` 初始为 `-1`：

```text
-1 表示尚未访问，也表示最终不可达
```

起点必须是通路格子，然后设置：

```cpp
distance_[start.row][start.column] = 0;
pending.push(start);
```

队列中的坐标是值，因此不需要手动 `new` 和 `delete`。

## 4. 扩展八个方向

方向数组成对出现：

```cpp
const int rowOffset[] = {-1, -1, -1, 0, 1, 1, 1, 0};
const int columnOffset[] = {-1, 0, 1, 1, 1, 0, -1, -1};
```

对当前位置 `(r, c)`，第 `direction` 个候选位置是：

```cpp
Point next{
    r + rowOffset[direction],
    c + columnOffset[direction]
};
```

其中前三个方向是上方，中间两个是左右，后三个是下方。

## 5. 扩展条件

新位置同时满足：

```cpp
if (IsOpen(next) && distance_[next.row][next.column] == -1) {
    distance_[next.row][next.column] =
        distance_[current.row][current.column] + 1;
    pending.push(next);
}
```

- `IsOpen(next)`：位置在边界内且不是墙。
- `distance_ == -1`：位置之前没有入队。

设置距离后再入队，这个顺序很重要。如果等到出队才标记，同一位置可能被多次放入队。

## 6. 正确性和不可达位置

队列保证距离较小的层先处理。一个格子第一次被发现时，当前距离已经是最少步数，之后不再更新。

不可通行的墙和没有从起点连到的位置保持 `-1`。打印时用 `-` 表示它们。

## 7. 复杂度

每个格子最多入队一次，每次出队时检查固定的 `8` 个方向。如果迷宫有 `R` 行、`C` 列：

| 资源 | 复杂度 |
| --- | --- |
| 时间 | `O(RC)` |
| 距离数组 | `O(RC)` |
| BFS 队列 | `O(RC)` 最坏 |

## 8. 与原实现的区别

原代码使用全局数组、`malloc` 创建每个坐标，并使用 `1000` 作为“未到达”标记。重构后：

- 迷宫数据和距离被封装在 `Maze` 类中。
- 用 `std::vector` 保存不同大小的迷宫。
- 用 `std::queue<Point>` 直接保存坐标值，不会产生节点内存泄漏。
- 用 `-1` 明确表示未访问或不可达。
