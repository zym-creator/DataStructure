# 12. 堆的操作

> 对应源码：`code/12_堆的操作.cpp`

## 1. 什么是最大堆

堆是一棵完全二叉树，通常用数组紧凑存储。最大堆要求每个父节点都不小于它的孩子，因此根节点始终是堆中最大值。

源码使用动态数组 `ElementType* elements_` 存储元素，并自己维护元素数量 `size_` 和容量 `capacity_`。索引从 `0` 开始，对于索引 `i`：

```text
父节点：(i - 1) / 2
左孩子：2 * i + 1
右孩子：2 * i + 2
```

完全二叉树不需要在数组中留空位，数组的顺序就是它的层序遍历顺序。

## 2. 插入与上滤

新元素先放到数组末尾，以保持完全二叉树的形状。如果它大于父节点，就与父节点交换，并继续向上比较：

```cpp
while (index > 0) {
    const int parent = Parent(index);
    if (elements_[parent] >= elements_[index]) {
        break;
    }
    const ElementType temporary = elements_[parent];
    elements_[parent] = elements_[index];
    elements_[index] = temporary;
    index = parent;
}
```

这个过程称为上滤。最多经过从叶子到根的一条路径，时间复杂度为 `O(log n)`。

## 3. 删除最大值与下滤

最大值位于数组首部。删除时按以下步骤处理：

1. 保存根节点的值。
2. 用数组末尾元素覆盖根节点，再删除末尾。
3. 将新根与两个孩子中较大的一个比较。
4. 如果新根较小，就与较大孩子交换，并继续向下。

选择较大的孩子才能保证交换后父节点同时不小于左右孩子。下滤的时间复杂度也是 `O(log n)`。

## 4. 空堆与容量处理

`Insert` 在堆满时返回 `false`。`DeleteMax` 和 `GetMax` 使用“`bool` 返回值 + 引用参数”：

- 操作成功时，把结果写入引用参数并返回 `true`。
- 堆为空时，返回 `false`，不使用引用参数。

这比返回 `-1` 之类的特殊整数更安全，因为任意整数（包括 `-1`）都可以作为堆的正常元素。

构造函数使用 `new[]` 申请数组，析构函数使用 `delete[]` 释放数组。由于默认的拷贝只会复制指针，可能导致两个对象重复释放同一块内存，因此示例显式禁用了拷贝构造和拷贝赋值。

## 5. 复杂度

| 操作 | 时间复杂度 |
| --- | --- |
| 查看最大值 | `O(1)` |
| 插入 | `O(log n)` |
| 删除最大值 | `O(log n)` |
| 层序遍历 | `O(n)` |
| 判断空、满或获取元素数 | `O(1)` |

存储 `n` 个堆元素需要 `O(n)` 空间。

## 6. 与原 C 风格实现的区别

重构后将数据和操作封装在 `MaxHeap` 类中，不再暴露内部数组。同时取消了人工设置的超大哨兵，所以插入值不再受“必须小于哨兵”的隐含限制。

数组改为从 `0` 开始后，与 C++ 数组的下标习惯一致，也不再浪费 `Elements[0]` 的空间。整个实现只引入 `<iostream>`，数组存储、元素交换、上滤和下滤都在类内手动完成。
