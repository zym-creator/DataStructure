# 5. 链表实现的栈

> 对应源码：`code/5_栈的链表实现.cpp`

## 1. 基本概念

栈遵守后进先出（LIFO）。本文件使用单链表存储栈，把链表头部当作栈顶：

```text
top_ -> [66 | next] -> [7 | next] -> [5 | nullptr]
```

入栈和出栈都只在头部操作，不需要遍历整个链表。

## 2. 节点和栈顶

```cpp
struct Node {
    ElementType data;
    Node* next;
};

Node* top_ = nullptr;
int size_ = 0;
```

- `data` 保存节点中的数据。
- `next` 指向下一个节点。
- `top_` 指向栈顶节点。
- `size_` 记录节点数量。
- 空栈时 `top_ == nullptr` 且 `size_ == 0`。

## 3. 入栈 `Push`

```cpp
bool Push(ElementType value) {
    Node* newNode = new Node{value, top_};
    top_ = newNode;
    ++size_;
    return true;
}
```

1. 用 `new` 申请新节点。
2. 让新节点的 `next` 指向原来的栈顶。
3. 让 `top_` 指向新节点。
4. 将 `size_` 加一。

链栈没有固定的 `MaxSize`，只要内存足够就可以继续入栈。

## 4. 出栈 `Pop`

```cpp
bool Pop(ElementType& value) {
    if (IsEmpty()) {
        return false;
    }

    Node* nodeToDelete = top_;
    value = nodeToDelete->data;
    top_ = nodeToDelete->next;
    delete nodeToDelete;
    --size_;
    return true;
}
```

1. 检查是否空栈。
2. 保存当前栈顶节点。
3. 读取节点的数据。
4. 让 `top_` 指向下一个节点。
5. 用 `delete` 释放原栈顶节点。
6. 将 `size_` 减一。

## 5. 析构函数和 `Clear`

```cpp
~LinkedStack() {
    Clear();
}
```

对象销毁时会自动释放所有节点，避免内存泄漏。代码禁止默认拷贝，因为只拷贝 `top_` 地址会让两个对象共享同一批节点。

## 6. 后缀表达式求值

后缀表达式把运算符放在操作数后面：

```text
2 + 3       -> 2 3 +
2 3 + 4 * 5 -> 15
```

求值时：

1. 遇到数字就入栈。
2. 遇到运算符，先出栈右操作数，再出栈左操作数。
3. 计算后将结果入栈。
4. 最后栈中只剩一个数时，该数就是结果。

本实现支持多位整数、负数以及 `+` 、`-` 、`*` 、`/`，数字之间使用空格分隔。

## 7. 复杂度

| 操作 | 时间复杂度 | 额外空间 |
| --- | --- | --- |
| `Push` | `O(1)` | 每次新建一个节点 |
| `Pop` | `O(1)` | 释放一个节点 |
| 后缀表达式求值 | `O(n)` | `O(n)` |

## 8. 和数组栈的对比

| 对比项 | 数组栈 | 链式栈 |
| --- | --- | --- |
| 容量 | 固定 | 按需创建，受可用内存限制 |
| 入栈 | `O(1)` | `O(1)` |
| 出栈 | `O(1)` | `O(1)` |
| 额外内存 | 不需要指针 | 每个节点需要 `next` |
| 实现难度 | 较简单 | 需要管理 `new/delete` |
