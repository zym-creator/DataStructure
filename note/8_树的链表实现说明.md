# 8. 二叉树的链表实现

> 对应源码：`code/8_树的链表实现.cpp`

## 1. 二叉树

二叉树中每个节点最多有两个孩子，分别称为左孩子和右孩子。

```cpp
struct Node {
    ElementType data;
    Node* left;
    Node* right;
};
```

```text
        1
      /   \
     2     3
    / \   / \
   4   6 7   9
      /   \
     5     8
```

`root_` 指向根节点，空树中 `root_ == nullptr`。

## 2. 四种遍历

| 遍历 | 顺序 | 当前树的结果 |
| --- | --- | --- |
| 先序 | 根、左、右 | `1 2 4 6 5 3 7 8 9` |
| 中序 | 左、根、右 | `4 2 5 6 1 7 8 3 9` |
| 后序 | 左、右、根 | `4 5 6 2 8 7 9 3 1` |
| 层序 | 从上到下、从左到右 | `1 2 3 4 6 7 9 5 8` |

前三种遍历使用递归。层序遍历使用程序自己实现的链式队列，没有使用 `std::queue`。

### 先序遍历

```cpp
std::cout << node->data;
PreOrder(node->left);
PreOrder(node->right);
```

### 中序遍历

```cpp
InOrder(node->left);
std::cout << node->data;
InOrder(node->right);
```

### 后序遍历

```cpp
PostOrder(node->left);
PostOrder(node->right);
std::cout << node->data;
```

## 3. 叶子节点

没有左孩子，也没有右孩子的节点叫叶子节点：

```cpp
if (node->left == nullptr && node->right == nullptr) {
    std::cout << node->data;
}
```

当前树的叶子节点是 `4`、`5`、`8`和 `9`。

## 4. 树的高度

空树高度为 `0`。非空树的高度是左右子树高度的较大值加一：

```cpp
int leftHeight = GetHeight(node->left);
int rightHeight = GetHeight(node->right);
return (leftHeight > rightHeight ? leftHeight : rightHeight) + 1;
```

## 5. 内存释放

释放树时必须先释放左右子树，再释放当前节点：

```cpp
Destroy(node->left);
Destroy(node->right);
delete node;
```

这个顺序和后序遍历相同。

## 6. 复杂度

- 四种遍历的时间复杂度都是 `O(n)`。
- 查找叶子节点是 `O(n)`。
- 计算高度是 `O(n)`。
- 递归额外空间与树高 `h` 有关，为 `O(h)`。
