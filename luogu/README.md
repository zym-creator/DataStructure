# 洛谷数据结构循序渐进题单

本题单与项目 `notes/00-12` 的学习顺序配套，目标是从 C++ 基础过渡到数据结构课程核心算法。

## 使用方法

1. 先阅读对应的 `notes/` 章节，再做题。
2. 每题独立思考 20-40 分钟；完全没思路时先看知识点，不直接抄完整题解。
3. 通过后记录时间复杂度、错误原因，并在题目前把 `[ ]` 改为 `[x]`。
4. 标记为“复做”的题，在 1 天、7 天、30 天后各重写一次。
5. 同一阶段正确率达到约 70%，再进入下一阶段；卡题可以暂时跳过。

## 难度标记

这里使用自定义学习难度，不保证与洛谷当前颜色完全一致：

- `L1`：语法与模拟入门
- `L2`：单一知识点模板
- `L3`：需要选择数据结构或处理边界
- `L4`：多个知识点结合
- `L5`：课程拓展或提高题

## 注意事项

- **[注意]** 先确认数据范围，再选择 O(n)、O(n log n) 或 O(n²)。
- **[注意]** 数组大小、下标范围和 `long long` 溢出是最常见的非算法错误。
- **[注意]** 不要只背模板。提交前应能口述数据结构维护了什么信息。
- **[拓展]** 各文件末尾的 L5 不是完成课程核心的必要条件。
