## 示例说明

### `code/线性结构.cpp`

顺序表的 C++ 实现，使用 `std::array` 管理固定容量的数据，不需要 `malloc` 或手动 `free`。

包含以下操作：

- `Insert`：按下标插入元素
- `Delete`：按下标删除元素
- `Find`：按值查找元素第一次出现的位置
- `FindKth`：按下标访问元素
- `Length`：获取当前线性表长度

编译并运行：

```bash
g++ -std=c++17 -Wall -Wextra -pedantic code/线性结构.cpp -o linear_structure
./linear_structure
```

### `code/复杂度.cpp`

通过最大连续子列和问题，展示五种不同复杂度的算法：

| 方法 | 时间复杂度 | 核心思想 |
|---|---:|---|
| 方法一 | `O(n^3)` | 枚举起点、终点并重新求和 |
| 方法二 | `O(n^2)` | 固定起点并持续累加 |
| 方法三 | `O(n^2)` | 使用累计和减少部分重复计算 |
| 方法四 | `O(n log n)` | 分治并合并跨越中点的答案 |
| 方法五 | `O(n)` | Kadane 算法，丢弃负的前缀和 |

该文件保留为算法学习时的原始版本，当前代码没有在 `main` 前声明这些函数，因此部分标准 C++ 编译器会报告“函数未声明”。如果需要运行它，需要先添加函数声明，或将 `main` 移到各函数定义之后。

## 编译环境

建议使用支持 C++17 的编译器，例如：

```bash

```

编译时开启警告选项，有助于及时发现未声明函数、类型转换和边界相关问题：

```bash
g++ -std=c++17 -Wall -Wextra -pedantic <source>.cpp -o <program>
```
