# DataStructure：数据结构自学教程（C++）

这是一套按本科《数据结构》课程主线编排的自学材料。内容覆盖北邮及多数高校数据结构课程的共同核心；不同年份、学院和教师的教学顺序可能不同，请以当学期教学大纲为准。

## 学习顺序

| 章 | 主题 | 必须掌握 |
|---|---|---|
| 00 | C++ 内存与资源管理 | 指针、析构、深拷贝、Rule of Five、RAII |
| 01 | 复杂度 | 渐进记号、递归复杂度、均摊分析 |
| 02 | 数组与顺序表 | 动态扩容、插入删除、模板容器 |
| 03 | 链表 | 单/双/循环链表、哨兵、反转、快慢指针 |
| 04 | 栈 | 顺序栈、链栈、括号匹配、表达式 |
| 05 | 队列 | 循环队列、链队列、双端队列、BFS |
| 06 | 串 | 朴素匹配、KMP、next 数组 |
| 07 | 数组、矩阵与广义表 | 多维数组、稀疏矩阵、三元组、递归结构 |
| 08 | 树与二叉树 | 遍历、性质、线索化思想、BST |
| 09 | Huffman、堆与并查集 | 编码、优先队列、集合合并 |
| 10 | 图 | 存储、DFS/BFS、生成树、最短路、拓扑排序 |
| 11 | 查找 | 顺序/折半、BST、AVL、散列表 |
| 12 | 排序 | 插入、交换、选择、归并、基数及稳定性 |

每章先读 `notes/`，再运行对应的 `code/`。文档中的标记含义：

- **[注意]**：考试和编码中常见错误。
- **[边界]**：必须单独验证的输入。
- **[拓展]**：超出基础课程主线，可在掌握正文后学习。
- **[工程实践]**：帮助写出可靠现代 C++，未必是笔试重点。

## 构建与运行

要求支持 C++17 的编译器和 CMake 3.16+：

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

也可以只编译一章：

```bash
c++ -std=c++17 -Wall -Wextra -Wpedantic code/08_树_二叉树.cpp -o tree
./tree
```

## 推荐自学方法

1. 先画结构和操作过程，不看代码口述复杂度。
2. 手写核心操作，再与示例对照。
3. 至少测试空结构、单元素、满结构、重复元素和非法输入。
4. 对树和图，先在纸上写出遍历顺序，再运行程序。
5. 对排序，手工完成一趟并说明稳定性、时间和空间复杂度。

**[注意]** 示例以教学可读性为首要目标，但仍遵守资源管理和边界检查。实际项目优先使用标准库容器，手写容器主要用于理解原理。
