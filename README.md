# DataStructure：数据结构自学教程（C++）

这是一套按本科《数据结构》课程主线编排的自学材料。内容覆盖北邮及多数高校数据结构课程的共同核心；不同年份、学院和教师的教学顺序可能不同，请以当学期教学大纲为准。

## 学习顺序（按课件章节）

| 章 | 主题 | 必须掌握 |
|---|---|---|
| 00 | 课程介绍 | 教材、考核方式与课程主线 |
| 01 | 绪论与算法分析 | 基本概念、抽象数据类型、复杂度与 C++ 基础 |
| 02 | 线性表 | 顺序表、链表及多项式应用 |
| 03 | 栈与队列 | LIFO/FIFO、循环队列及典型应用 |
| 04 | 串 | 串的表示、基本操作、模式匹配与 KMP |
| 05 | 数组和广义表 | 多维数组、特殊矩阵、广义表与递归 |
| 06 | 树结构 | 二叉树、遍历、线索树、Huffman、树与森林 |
| 07 | 图结构 | 存储、遍历、MST、拓扑排序、关键路径、最短路 |
| 09 | 查找 | 顺序/折半、BST、AVL、散列表与分块查找 |
| 10 | 内部排序 | 插入、交换、选择、归并、堆、基数排序 |
| 11 | 外部排序 | 外存访问、多路归并、置换选择、最佳归并树 |
| 12 | 综合示例 | 内部排序代码与工程化实现 |

仓库中的文件按“可独立运行的专题”组织，编号不完全等同于课件章节。每章先读 `notes/`，再运行对应的 `code/`。文档中的标记含义：

- **[注意]**：考试和编码中常见错误。
- **[边界]**：必须单独验证的输入。
- **[拓展]**：超出基础课程主线，可在掌握正文后学习。
- **[工程实践]**：帮助写出可靠现代 C++，未必是笔试重点。

## 构建与运行

要求支持 C++17 的编译器和 CMake 3.16+：

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

也可以只编译一章：

```bash
c++ -std=c++17 -Wall -Wextra -Wpedantic code/08_树_二叉树.cpp -o tree
./tree
```

## 推荐自学方法

1. 先画结构和操作过程，不看代码口述复杂度。
2. 手写核心操作，再与示例对照。
3. 至少测试空结构、单元素、满结构、重复元素和非法输入。
4. 对树和图，先在纸上写出遍历顺序，再运行程序。
5. 对排序，手工完成一趟并说明稳定性、时间和空间复杂度。

**[注意]** 示例以教学可读性为首要目标，但仍遵守资源管理和边界检查。实际项目优先使用标准库容器，手写容器主要用于理解原理。
