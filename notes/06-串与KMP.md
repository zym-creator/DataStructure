# 06 串与 KMP

串是字符的有限序列。模式匹配问题是：在主串 `text` 中寻找模式串 `pattern` 第一次出现的位置。

## 1. 朴素匹配

从主串每个可能起点出发逐字符比较。失配后主串起点右移一位。

- 最坏时间复杂度：O(nm)。
- 额外空间：O(1)。

**[边界]** 空模式通常约定匹配位置为 0；模式比主串长则匹配失败。接口应明确失败时返回什么，本项目使用 `std::string::npos`。

## 2. KMP 的核心

朴素算法在失配后丢弃了已经匹配的信息。KMP 利用模式串自身的相同前缀和后缀，让模式串跳转，主串指针不回退。

定义 `lps[i]`：`pattern[0..i]` 的最长“相等真前缀与真后缀”长度。真前缀不能等于整个串。

模式 `ababaca` 的 LPS：

```text
字符: a b a b a c a
LPS : 0 0 1 2 3 0 1
```

构造 LPS 时：

1. 若 `pattern[i] == pattern[length]`，二者同时前进。
2. 若失配且 `length > 0`，令 `length = lps[length - 1]`，继续尝试更短边界。
3. 若 `length == 0` 仍失配，`lps[i] = 0`。

搜索时失配也按相同思想令 `j = lps[j - 1]`。

- 预处理：O(m)。
- 匹配：O(n)。
- 空间：O(m)。

## 3. 为什么是线性时间

搜索过程中主串下标只前进不后退；模式下标虽然可能回退，但每次回退都缩短已匹配前缀，累计次数受前进次数限制，因此总操作数是 O(n+m)。

**[注意]** 不同教材可能使用 `next`、`nextval` 或从 `-1` 开始的定义，数组数值会不同，但跳转思想相同。答题时必须先声明定义，不能混用公式。

## 4. 练习

1. 手算 `aabaaab` 的 LPS。
2. 跟踪 `text = "abababca"`、`pattern = "ababca"` 的匹配过程。
3. 修改代码返回全部匹配位置，并考虑重叠匹配，例如 `aaa` 中的 `aa`。

**[拓展]** 多模式匹配可学习 Trie 与 Aho-Corasick；超长文本搜索可了解 Rabin-Karp 和滚动哈希。
