# 树：完整知识点、代码与期末复习

> 面向学过基础 C++ 的学生。本文约定：根节点在第 1 层；空树高度为 0；单节点树高度为 1。不同教材可能把根的深度记为 0、把高度按边数计算，做题前一定先看题目定义。

## 1. 树的基本概念

树是一种“一对多”的层次结构。除根外，每个节点只有一个父节点。

```text
        A
      / | \
     B  C  D
    / \     \
   E   F     G
```

- **节点**：图中的 A～G；**根节点**：最顶端 A。
- **父/子节点**：A 是 B 的父，B 是 A 的子；**兄弟节点**：同一父亲的 B、C、D。
- **祖先/后代**：A、B 都是 E 的祖先；E 是 A、B 的后代。
- **叶子节点**：没有孩子的 C、E、F、G；**内部节点**：至少有一个孩子的 A、B、D（根也可以是内部节点）。
- **节点的度**：孩子数，如 A 的度为 3；**树的度**：所有节点度的最大值，本树为 3。
- **层次**：根为第 1 层，它的孩子为第 2 层。**深度**：从根到该节点所处的层次（本文根深度为 1）。**高度**：以该节点为根的子树最多有多少层；整树高度为 3。
- **路径**：相邻节点连成的序列，如 A-B-E；**路径长度**：经过的边数，所以 A 到 E 长度为 2。
- **子树**：某节点及其全部后代构成的树。B、E、F 构成 B 的子树。
- **森林**：若干棵互不相交的树。删去 A 后，B、C、D 的三棵子树组成森林。
- **有序树**：孩子有明确先后次序，交换孩子会变成另一棵树；**无序树**：只关心亲子关系，不关心孩子次序。

一棵有 `n` 个节点的非空树满足 **边数 = 节点数 - 1**。原因是根没有入边，其余每个节点都恰好用一条边连接父节点，共 `n-1` 条。也可从一个节点开始，每增加一个节点，为保持连通且无环必须增加一条边。

## 2. 二叉树基础

**二叉树**是每个节点最多有两个孩子的有序树，两个位置分别称左子树和右子树；即使只有一个孩子，也必须分清是左还是右。没有节点的是**空二叉树**。

- **斜树**：每个内部节点都只有一个孩子，像链表；全向左叫左斜树。
- **满二叉树**：每层都达到最大节点数，即所有内部节点都有两个孩子且叶子在同一层。
- **完全二叉树**：除最后一层外都满，最后一层节点从左向右连续排列。
- **二叉搜索树（BST）**：左子树值小于根，右子树值大于根，左右子树也满足该规则。
- **平衡二叉树**：通常指任意节点左右子树高度差不超过 1；AVL 还要求它是 BST。

```text
满二叉树（也是完全二叉树）   完全但不满             不是完全二叉树
       A                     A                        A
     /   \                 /   \                    / \
    B     C               B     C                  B   C
   / \   / \             / \                      \ /
  D  E  F  G            D   E                      D E
                                                  （出现空位后又有节点）
```

满一定完全，完全不一定满。完全二叉树强调“编号连续”，很适合数组存储。

## 3. 二叉树性质与推导

1. 第 `i` 层最多 `2^(i-1)` 个节点。第 1 层为 1；每个节点最多生两个孩子，逐层乘 2。
2. 高度为 `h` 时最多 `1+2+...+2^(h-1)=2^h-1` 个节点，这是等比数列求和。
3. 含 `n` 个节点的完全二叉树高度为 `floor(log2(n))+1`，也等于 `ceil(log2(n+1))`。因为 `2^(h-1) <= n <= 2^h-1`。
4. 设叶子数为 `n0`，度为 1、2 的节点数为 `n1,n2`。节点数 `n=n0+n1+n2`；边数既是 `n-1`，也是度数之和 `n1+2n2`。联立得 `n0=n2+1`。
5. 一般树同样满足：所有节点的度数之和 = 边数 = 节点总数 - 1。

性质计算例题：

1. 高度 5 的二叉树最多多少节点？答：`2^5-1=31`。
2. 完全二叉树有 20 个节点，高度多少？答：`floor(log2 20)+1=5`。
3. 某二叉树度为 2 的节点有 8 个，叶子多少？答：9。
4. 有 30 个节点的树有多少条边？答：29。
5. 二叉树有 10 个叶子、6 个度为 1 的节点，总节点数？答：`n2=9`，总数 `10+6+9=25`。

## 4. 二叉树存储

### 4.1 顺序存储

完全二叉树按层序放入下标从 0 开始的数组。节点下标为 `i` 时：左孩子 `2*i+1`，右孩子 `2*i+2`；当 `i>0` 时父节点 `(i-1)/2`。这些公式要求数组位置与完全二叉树编号一致；普通稀疏二叉树要保留空位，否则关系会错。访问孩子前必须检查下标 `< n`，访问父亲前必须检查 `i>0`。

### 4.2 链式存储与内存

后续二叉树代码统一复用：

```cpp
using namespace std;

struct TreeNode {
    int data;
    TreeNode* left;
    TreeNode* right;
};

// 创建一个叶子节点
TreeNode* createNode(int value) {
    TreeNode* node = new TreeNode;
    node->data = value;
    node->left = NULL;
    node->right = NULL;
    return node;
}

// 后序释放：必须先释放孩子，再释放根
void destroyTree(TreeNode* root) {
    if (root == NULL) return;
    destroyTree(root->left);
    destroyTree(root->right);
    delete root;
}
```

`new` 从堆区申请内存，不会在函数结束时自动归还；不用 `delete` 会造成内存泄漏。每个节点只 `delete` 一次，释放后不可再访问。

## 5. 完整程序一：建树与四种遍历

示例树：

```text
        1
      /   \
     2     3
    / \     \
   4   5     6
```

先序为 `1 2 4 5 3 6`，中序为 `4 2 5 1 3 6`，后序为 `4 5 2 6 3 1`，层序为 `1 2 3 4 5 6`。手算时分别按“根左右、左根右、左右根”和逐层从左到右记录。递归框架始终是处理根、递归左、递归右，只需移动“输出根”的位置。

<!-- PROGRAM: traversal -->
```cpp
#include <iostream>
#include <stack>
#include <queue>
using namespace std;

struct TreeNode { int data; TreeNode* left; TreeNode* right; };

// 创建节点
TreeNode* createNode(int x) {
    TreeNode* p = new TreeNode;
    p->data = x; p->left = NULL; p->right = NULL;
    return p;
}

// 根、左、右
void preorder(TreeNode* root) {
    if (root == NULL) return;
    cout << root->data << " ";
    preorder(root->left); preorder(root->right);
}
// 左、根、右
void inorder(TreeNode* root) {
    if (root == NULL) return;
    inorder(root->left); cout << root->data << " "; inorder(root->right);
}
// 左、右、根
void postorder(TreeNode* root) {
    if (root == NULL) return;
    postorder(root->left); postorder(root->right); cout << root->data << " ";
}
// 队列保存下一层待访问节点
void levelorder(TreeNode* root) {
    if (root == NULL) return;
    queue<TreeNode*> q; q.push(root);
    while (!q.empty()) {
        TreeNode* p = q.front(); q.pop();
        cout << p->data << " ";
        if (p->left != NULL) q.push(p->left);
        if (p->right != NULL) q.push(p->right);
    }
}
// 栈后进先出，所以先压右、再压左
void preorderIter(TreeNode* root) {
    if (root == NULL) return;
    stack<TreeNode*> s; s.push(root);
    while (!s.empty()) {
        TreeNode* p = s.top(); s.pop(); cout << p->data << " ";
        if (p->right != NULL) s.push(p->right);
        if (p->left != NULL) s.push(p->left);
    }
}
// 一路压入左链，弹出根后转向右子树
void inorderIter(TreeNode* root) {
    stack<TreeNode*> s; TreeNode* p = root;
    while (p != NULL || !s.empty()) {
        while (p != NULL) { s.push(p); p = p->left; }
        p = s.top(); s.pop(); cout << p->data << " "; p = p->right;
    }
}
// 双栈：第二个栈把“根右左”反转为“左右根”
void postorderIter(TreeNode* root) {
    if (root == NULL) return;
    stack<TreeNode*> s1, s2; s1.push(root);
    while (!s1.empty()) {
        TreeNode* p = s1.top(); s1.pop(); s2.push(p);
        if (p->left != NULL) s1.push(p->left);
        if (p->right != NULL) s1.push(p->right);
    }
    while (!s2.empty()) { cout << s2.top()->data << " "; s2.pop(); }
}
// 递归后序释放全部 new 出来的节点
void destroyTree(TreeNode* root) {
    if (root == NULL) return;
    destroyTree(root->left); destroyTree(root->right); delete root;
}
int main() {
    TreeNode* root = createNode(1);
    root->left = createNode(2); root->right = createNode(3);
    root->left->left = createNode(4); root->left->right = createNode(5);
    root->right->right = createNode(6);
    cout << "pre: "; preorder(root); cout << "\n";
    cout << "in: "; inorder(root); cout << "\n";
    cout << "post: "; postorder(root); cout << "\n";
    cout << "level: "; levelorder(root); cout << "\n";
    cout << "iter pre/in/post: "; preorderIter(root); cout << "| ";
    inorderIter(root); cout << "| "; postorderIter(root); cout << "\n";
    destroyTree(root); return 0;
}
```

四种遍历都访问每个节点一次：时间 `O(n)`。递归遍历辅助空间为树高 `O(h)`；层序队列最坏 `O(n)`；栈版本最坏 `O(n)`。

## 6. 完整程序二：常见递归统计

通用结构是：①处理空树；②递归左子树；③递归右子树；④合并结果。递归出口通常是 `root == NULL`。

<!-- PROGRAM: recursive -->
```cpp
#include <iostream>
#include <queue>
#include <algorithm>
using namespace std;
struct TreeNode { int data; TreeNode* left; TreeNode* right; };
TreeNode* createNode(int x) { TreeNode* p=new TreeNode; p->data=x; p->left=p->right=NULL; return p; }

// 空树贡献 0；根贡献 1
int countNodes(TreeNode* r) { return r==NULL ? 0 : 1+countNodes(r->left)+countNodes(r->right); }
// 只有左右都空才是叶子
int countLeaves(TreeNode* r) {
    if (r==NULL) return 0;
    if (r->left==NULL && r->right==NULL) return 1;
    return countLeaves(r->left)+countLeaves(r->right);
}
// 异或思想：恰好一个孩子非空
int countDegree1(TreeNode* r) {
    if (r==NULL) return 0;
    int self=(r->left==NULL)!=(r->right==NULL);
    return self+countDegree1(r->left)+countDegree1(r->right);
}
int countDegree2(TreeNode* r) {
    if (r==NULL) return 0;
    int self=(r->left!=NULL && r->right!=NULL);
    return self+countDegree2(r->left)+countDegree2(r->right);
}
// 空树高 0，非空树为较高子树加 1
int height(TreeNode* r) { return r==NULL ? 0 : 1+max(height(r->left),height(r->right)); }
// 本文根在第 1 层
int countLevel(TreeNode* r, int k) {
    if (r==NULL || k<=0) return 0;
    if (k==1) return 1;
    return countLevel(r->left,k-1)+countLevel(r->right,k-1);
}
// 先在根找，再找左右子树
TreeNode* findValue(TreeNode* r,int x) {
    if (r==NULL || r->data==x) return r;
    TreeNode* p=findValue(r->left,x);
    return p!=NULL ? p : findValue(r->right,x);
}
bool sameTree(TreeNode* a,TreeNode* b) {
    if (a==NULL && b==NULL) return true;
    if (a==NULL || b==NULL || a->data!=b->data) return false;
    return sameTree(a->left,b->left)&&sameTree(a->right,b->right);
}
TreeNode* copyTree(TreeNode* r) {
    if (r==NULL) return NULL;
    TreeNode* p=createNode(r->data);
    p->left=copyTree(r->left); p->right=copyTree(r->right); return p;
}
void mirror(TreeNode* r) {
    if (r==NULL) return;
    TreeNode* t=r->left; r->left=r->right; r->right=t;
    mirror(r->left); mirror(r->right);
}
// 满二叉树：每个节点要么 0 个孩子，要么 2 个孩子
bool isFull(TreeNode* r) {
    if (r==NULL) return true;
    if ((r->left==NULL)!=(r->right==NULL)) return false;
    return isFull(r->left)&&isFull(r->right);
}
// 层序遇到空位后，不允许再遇到非空节点
bool isComplete(TreeNode* r) {
    if (r==NULL) return true;
    queue<TreeNode*> q; q.push(r); bool seenNull=false;
    while(!q.empty()) {
        TreeNode* p=q.front(); q.pop();
        if(p==NULL) seenNull=true;
        else { if(seenNull) return false; q.push(p->left); q.push(p->right); }
    }
    return true;
}
void destroyTree(TreeNode* r) { if(r!=NULL){ destroyTree(r->left); destroyTree(r->right); delete r; } }
int main() {
    TreeNode* r=createNode(1); r->left=createNode(2); r->right=createNode(3);
    r->left->left=createNode(4); r->left->right=createNode(5);
    TreeNode* c=copyTree(r);
    cout<<countNodes(r)<<" "<<countLeaves(r)<<" "<<countDegree1(r)<<" "<<countDegree2(r)<<"\n";
    cout<<height(r)<<" "<<countLevel(r,3)<<" "<<(findValue(r,5)!=NULL)<<"\n";
    cout<<sameTree(r,c)<<" "<<isFull(r)<<" "<<isComplete(r)<<"\n";
    mirror(c); destroyTree(c); destroyTree(r); return 0;
}
```

以上函数时间均为 `O(n)`（查找最好 `O(1)`，最坏 `O(n)`）；递归空间 `O(h)`。完全性判断时间、空间均最坏 `O(n)`。复制会额外创建 `n` 个节点，空间 `O(n)`。

## 7. 根据遍历序列还原二叉树

值互不重复时，先序首项或后序末项确定根；在中序中找到根即可分开左右子树。只给先序和后序通常不能唯一确定：先序 `AB`、后序 `BA` 时，B 可以是 A 的左孩子，也可以是右孩子。

例：先序 `A B D E C F`，中序 `D B E A C F`。A 为根；中序左段 `D B E`、右段 `C F`；左子树根 B，右子树根 C，继续切分，得到第 5 节示例形状。

下列函数依赖第 4 节 `TreeNode/createNode/destroyTree`。`ok` 变为 false 表示长度不符、根找不到等非法输入；调用者此时应释放返回树。

```cpp
using namespace std;

// 在线性区间寻找根；找不到返回 -1
int findInorder(const vector<int>& in,int l,int r,int x) {
    for(int i=l;i<=r;i++) if(in[i]==x) return i;
    return -1;
}
TreeNode* buildPreInPart(const vector<int>& pre,int pl,int pr,
                         const vector<int>& in,int il,int ir,bool& ok) {
    if(!ok) return NULL;
    if(pl>pr && il>ir) return NULL;
    if(pl>pr || il>ir || pr-pl!=ir-il) { ok=false; return NULL; }
    int k=findInorder(in,il,ir,pre[pl]);
    if(k==-1) { ok=false; return NULL; }
    int leftSize=k-il; TreeNode* r=createNode(pre[pl]);
    r->left=buildPreInPart(pre,pl+1,pl+leftSize,in,il,k-1,ok);
    r->right=buildPreInPart(pre,pl+leftSize+1,pr,in,k+1,ir,ok);
    return r;
}
TreeNode* buildPreIn(const vector<int>& pre,const vector<int>& in,bool& ok) {
    ok=pre.size()==in.size();
    if(!ok || pre.empty()) return NULL;
    return buildPreInPart(pre,0,(int)pre.size()-1,in,0,(int)in.size()-1,ok);
}
TreeNode* buildPostInPart(const vector<int>& post,int pl,int pr,
                          const vector<int>& in,int il,int ir,bool& ok) {
    if(!ok) return NULL;
    if(pl>pr && il>ir) return NULL;
    if(pl>pr || il>ir || pr-pl!=ir-il) { ok=false; return NULL; }
    int k=findInorder(in,il,ir,post[pr]);
    if(k==-1) { ok=false; return NULL; }
    int leftSize=k-il; TreeNode* r=createNode(post[pr]);
    r->left=buildPostInPart(post,pl,pl+leftSize-1,in,il,k-1,ok);
    r->right=buildPostInPart(post,pl+leftSize,pr-1,in,k+1,ir,ok);
    return r;
}
TreeNode* buildPostIn(const vector<int>& post,const vector<int>& in,bool& ok) {
    ok=post.size()==in.size();
    if(!ok || post.empty()) return NULL;
    return buildPostInPart(post,0,(int)post.size()-1,in,0,(int)in.size()-1,ok);
}
```

每层线性找根，最坏时间 `O(n^2)`；递归栈 `O(h)`，新树 `O(n)`。基础版便于考试书写。严格检查重复值还需先验证序列元素唯一且集合相同。

## 8. 完整程序三：二叉搜索树 BST

BST 不允许重复值。中序遍历严格递增。平均较平衡时查找、插入、删除 `O(log n)`；退化成斜树时最坏 `O(n)`。

```cpp
#include <iostream>
#include <climits>
using namespace std;
struct TreeNode { int data; TreeNode* left; TreeNode* right; };
TreeNode* createNode(int x){ TreeNode* p=new TreeNode; p->data=x; p->left=p->right=NULL; return p; }
TreeNode* searchRec(TreeNode* r,int x){
    if(r==NULL||r->data==x) return r;
    return x<r->data ? searchRec(r->left,x) : searchRec(r->right,x);
}
TreeNode* searchIter(TreeNode* r,int x){
    while(r!=NULL && r->data!=x) r=x<r->data?r->left:r->right;
    return r;
}
TreeNode* insertRec(TreeNode* r,int x){
    if(r==NULL) return createNode(x);
    if(x<r->data) r->left=insertRec(r->left,x);
    else if(x>r->data) r->right=insertRec(r->right,x); // 相等时不插入
    return r;
}
TreeNode* insertIter(TreeNode* r,int x){
    if(r==NULL) return createNode(x);
    TreeNode *p=r,*parent=NULL;
    while(p!=NULL){ parent=p; if(x==p->data)return r; p=x<p->data?p->left:p->right; }
    if(x<parent->data) parent->left=createNode(x); else parent->right=createNode(x);
    return r;
}
TreeNode* minimum(TreeNode* r){ if(r==NULL)return NULL; while(r->left!=NULL)r=r->left; return r; }
TreeNode* maximum(TreeNode* r){ if(r==NULL)return NULL; while(r->right!=NULL)r=r->right; return r; }
TreeNode* removeNode(TreeNode* r,int x){
    if(r==NULL) return NULL;
    if(x<r->data) r->left=removeNode(r->left,x);
    else if(x>r->data) r->right=removeNode(r->right,x);
    else {
        // 0 或 1 个孩子：让孩子接替并删除原节点
        if(r->left==NULL){ TreeNode* t=r->right; delete r; return t; }
        if(r->right==NULL){ TreeNode* t=r->left; delete r; return t; }
        // 两个孩子：用右子树最小值替换，再删除重复节点
        TreeNode* t=minimum(r->right); r->data=t->data;
        r->right=removeNode(r->right,t->data);
    }
    return r;
}
void inorder(TreeNode* r){ if(r!=NULL){ inorder(r->left); cout<<r->data<<" "; inorder(r->right); } }
// 用 long long 边界避免 INT_MIN/INT_MAX 本身被误判
bool isBSTRange(TreeNode* r,long long low,long long high){
    if(r==NULL)return true;
    if(r->data<=low||r->data>=high)return false;
    return isBSTRange(r->left,low,r->data)&&isBSTRange(r->right,r->data,high);
}
bool isBST(TreeNode* r){ return isBSTRange(r,LLONG_MIN,LLONG_MAX); }
// 中序计数，第 k 小；k 从 1 开始
TreeNode* kthPart(TreeNode* r,int k,int& count){
    if(r==NULL)return NULL;
    TreeNode* p=kthPart(r->left,k,count); if(p!=NULL)return p;
    count++; if(count==k)return r;
    return kthPart(r->right,k,count);
}
TreeNode* kthSmallest(TreeNode* r,int k){ int count=0; return k<=0?NULL:kthPart(r,k,count); }
// 前提：a、b 的值存在于该 BST
TreeNode* lowestCommonAncestor(TreeNode* r,int a,int b){
    while(r!=NULL){
        if(a<r->data&&b<r->data)r=r->left;
        else if(a>r->data&&b>r->data)r=r->right;
        else return r;
    }
```

## 9. 完整程序四：哈夫曼树与编码

**权值**是字符出现频率；根到叶子的**路径长度**是边数；叶子的**带权路径长度**是权值乘路径长度；全体之和为 `WPL`。哈夫曼树每次合并两个最小权值节点，使 WPL 最小。字符只放叶子，编码取左 0 右 1；任何编码都不是另一个的前缀，称**前缀编码**，因此可即时解码。

手算权值 `A:5,B:9,C:12,D:13`：合并 5+9=14，12+13=25，14+25=39。四个叶子深度都为 2，`WPL=(5+9+12+13)*2=78`。

```cpp

#include <queue>
#include <vector>
#include <string>
using namespace std;
struct HuffNode { char ch; int weight; HuffNode* left; HuffNode* right; };
struct CompareNode {
    // priority_queue 默认大者优先，反向比较得到小根堆
    bool operator()(HuffNode* a,HuffNode* b) const { return a->weight>b->weight; }
};
HuffNode* makeHuff(char ch,int w,HuffNode* l,HuffNode* r){
    HuffNode* p=new HuffNode; p->ch=ch;p->weight=w;p->left=l;p->right=r;return p;
}
HuffNode* buildHuffman(const vector<char>& chars,const vector<int>& weights){
    if(chars.empty()||chars.size()!=weights.size())return NULL;
    priority_queue<HuffNode*,vector<HuffNode*>,CompareNode> q;
    for(int i=0;i<(int)chars.size();i++) q.push(makeHuff(chars[i],weights[i],NULL,NULL));
    while(q.size()>1){
        HuffNode* a=q.top();q.pop(); HuffNode* b=q.top();q.pop();
        q.push(makeHuff('\0',a->weight+b->weight,a,b));
    }
    return q.top();
}

    printCodes(r->left,code+"0"); printCodes(r->right,code+"1");
}
int weightedPathLength(HuffNode* r,int depth){
    if(r==NULL)return 0;
    if(r->left==NULL&&r->right==NULL)return r->weight*depth;
    return weightedPathLength(r->left,depth+1)+weightedPathLength(r->right,depth+1);
}
```

## 10. 完整程序五：大根堆与堆排序

堆是用数组保存的完全二叉树。**大根堆**每个父节点不小于孩子；**小根堆**相反。插入先放末尾再**向上调整**；删除堆顶用末尾覆盖根，再**向下调整**。建堆从最后一个非叶子 `n/2-1` 向前下调。

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;
void siftUp(vector<int>& a,int i){
    while(i>0){ int p=(i-1)/2; if(a[p]>=a[i])break; swap(a[p],a[i]); i=p; }
}
void siftDown(vector<int>& a,int n,int i){
    while(2*i+1<n){
        int child=2*i+1;
        if(child+1<n&&a[child+1]>a[child])child++;
        if(a[i]>=a[child])break;
        swap(a[i],a[child]); i=child;
    }
}
```

## 11. 并查集

并查集把若干集合表示成若干棵树。`parent[x]` 是 x 的父亲；根满足 `parent[x]==x`。查找一路走到根；合并让一个根挂到另一个根；路径压缩会把沿途节点直接连根；按大小合并让小树挂到大树。

```cpp
using namespace std;

// 基础版：初始化、查找、合并
void initBasic(int parent[],int n){for(int i=0;i<n;i++)parent[i]=i;}
int findBasic(int parent[],int x){while(parent[x]!=x)x=parent[x];return x;}
void uniteBasic(int parent[],int a,int b){
    int ra=findBasic(parent,a),rb=findBasic(parent,b);
    if(ra!=rb)parent[ra]=rb;
}

// 优化版还需要 size 数组
void initSet(int parent[],int size[],int n){for(int i=0;i<n;i++){parent[i]=i;size[i]=1;}}
int findSet(int parent[],int x){
    if(parent[x]!=x)parent[x]=findSet(parent,parent[x]); // 路径压缩
    return parent[x];
}
void uniteSet(int parent[],int size[],int a,int b){
    int ra=findSet(parent,a),rb=findSet(parent,b); if(ra==rb)return;
    if(size[ra]<size[rb]){int t=ra;ra=rb;rb=t;}
    parent[rb]=ra;size[ra]+=size[rb];
}
bool sameSet(int parent[],int a,int b){return findSet(parent,a)==findSet(parent,b);}
```

基础版单次最坏 `O(n)`；路径压缩加按大小合并的均摊复杂度为 `O(alpha(n))`，`alpha` 增长极慢，可近似看作常数；空间 `O(n)`。

## 12. AVL 平衡二叉搜索树

**平衡因子** `BF=左子树高度-右子树高度`，AVL 每个节点 BF 只能为 -1、0、1。插入可能使祖先失衡：

```text
LL:      30          20       RR: 10             20
        /           /  \          \             /  \
       20   右旋   10  30          20   左旋   10  30
      /                              \
     10                               30

LR:      30          30          20
        /            /           /  \
       10  左旋10   20  右旋30  10  30
         \          /
         20        10

RL:  10              10          20
       \               \         /  \
       30  右旋30      20 左旋10 10  30
      /                  \
     20                  30
```

```cpp
using namespace std;

// 依赖：struct AVLNode { int data,height; AVLNode* left; AVLNode* right; };
int avlHeight(AVLNode* p){return p==NULL?0:p->height;}
int balanceFactor(AVLNode* p){return p==NULL?0:avlHeight(p->left)-avlHeight(p->right);}
void updateHeight(AVLNode* p){p->height=1+max(avlHeight(p->left),avlHeight(p->right));}
AVLNode* makeAVL(int x){AVLNode* p=new AVLNode;p->data=x;p->height=1;p->left=p->right=NULL;return p;}
AVLNode* rotateRight(AVLNode* y){
    AVLNode* x=y->left;AVLNode* middle=x->right;
    x->right=y;y->left=middle;updateHeight(y);updateHeight(x);return x;
}
AVLNode* rotateLeft(AVLNode* x){
    AVLNode* y=x->right;AVLNode* middle=y->left;
    y->left=x;x->right=middle;updateHeight(x);updateHeight(y);return y;
}
AVLNode* insertAVL(AVLNode* r,int x){
    if(r==NULL)return makeAVL(x);
    if(x<r->data)r->left=insertAVL(r->left,x);
    else if(x>r->data)r->right=insertAVL(r->right,x);
    else return r;
    updateHeight(r);int bf=balanceFactor(r);
    if(bf>1&&x<r->left->data)return rotateRight(r);                 // LL
    if(bf<-1&&x>r->right->data)return rotateLeft(r);                // RR
    if(bf>1&&x>r->left->data){r->left=rotateLeft(r->left);return rotateRight(r);} // LR
    if(bf<-1&&x<r->right->data){r->right=rotateRight(r->right);return rotateLeft(r);} // RL
    return r;
}
void destroyAVL(AVLNode* r){if(r!=NULL){destroyAVL(r->left);destroyAVL(r->right);delete r;}}
```

需包含 `<algorithm>` 并 `using namespace std;`。高度、BF 为 `O(1)`（保存高度）；旋转 `O(1)`；插入时间和递归空间均 `O(log n)`。

### 16.2 必背公式

- 边数 `=n-1=所有节点度数之和`。
- 第 i 层最多 `2^(i-1)`；高度 h 最多 `2^h-1`。
- 完全二叉树高度 `floor(log2 n)+1`。
- 二叉树 `n0=n2+1`。
- 0 下标：左 `2i+1`，右 `2i+2`，父 `(i-1)/2`。
- WPL `=Σ(叶子权值×根到叶子的边数)`。
- 平衡因子 `=左高-右高`。

### 16.4 常见错误清单

- 忘记空树出口；把层数与边数混用；把完全误写成满。
- 数组 0 下标公式写成 `2i`、`2i+1`；不检查越界。
- 非递归先序压栈顺序反；重建树左右区间差 1。
- BST 删除后忘记接收返回的新根；两个孩子时只复制值却不删除后继。
- 判断 BST 只比父子；第 k 小忘记 k 从 1 开始。
- 哈夫曼路径长度按节点数；堆排序有效长度未缩小。
- AVL 双旋顺序错或忘记更新高度；`new` 后忘记 `delete`。

### 16.5 树的递归题通用答题模板

```cpp
using namespace std;

// 示例模板：统计满足 condition 的节点数
bool condition(TreeNode* root);               // 由题意实现判断条件
int solve(TreeNode* root){
    if(root==NULL) return 0;                  // 空树答案
    int left=solve(root->left);               // 左子问题
    int right=solve(root->right);             // 右子问题
    int self=condition(root) ? 1 : 0;         // 根自身的贡献
    return left+right+self;                   // 合并本层答案
}
```

先明确函数“返回什么”，再写空树答案，最后考虑根自身贡献。答复杂度时写时间 `O(n)`、递归空间 `O(h)`。

### 16.6 BST 删除答题模板

先按大小递归定位；找到后：无左则返回右并删根；无右则返回左并删根；两边都有则找右子树最小节点，复制其值，再从右子树删除该值。始终写 `root=removeNode(root,x)` 接收可能变化的根。

### 16.7 哈夫曼树手算步骤

列权值并排序；每次圈出两个最小值；相加生成新值并重新排序；直到只剩根；左边标 0、右边标 1；读叶子编码；用 `Σw×depth` 验算 WPL。

### 16.8 堆调整手算步骤

建堆从 `n/2-1` 倒着下调；大根堆每次选较大孩子；若孩子大于父就交换并继续。排序时交换根与有效区末尾，末尾不再参与，再从根下调。

### 16.9 一页式考前速记

```text
树：n 个点 n-1 条边。二叉树：n0=n2+1。
层：根=1；空高=0；单点高=1。
遍历：先=根左右，中=左根右，后=左右根，层=队列。
完全树数组：L=2i+1，R=2i+2，P=(i-1)/2。
重建：先序看头，后序看尾，中序切左右；先+后通常不唯一。
BST：左<根<右，中序递增；删除两孩子找后继/前驱。
Huffman：反复合并最小两项；WPL=Σw×深度；左0右1。
堆：完全树+父子局部有序；插入上调，删顶下调，建堆O(n)。
AVL：BF=左高-右高；LL右旋，RR左旋，LR先左后右，RL先右后左。
并查集：找根、合并；路径压缩+按大小合并近似O(1)。
所有 new：最终后序 delete。
```

## 17. 复杂度总览与代码使用提示

树遍历和常见统计通常时间 `O(n)`、递归空间 `O(h)`；斜树 `h=n`，完全树 `h=O(log n)`。运行代码时每个完整程序应单独保存编译，因为它们各自有 `main` 和节点定义。函数片段需与其注明的节点结构、头文件放在同一源文件中。考试若不要求可运行程序，可省略输出和测试，但不能省略递归出口、指针重连与内存释放逻辑。
