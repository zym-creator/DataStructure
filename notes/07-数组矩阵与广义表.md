# 07 多维数组、稀疏矩阵与广义表

## 1. 多维数组的存储

C/C++ 的二维数组采用行优先存储。对于 `A[rows][cols]`，元素 `A[i][j]` 的线性偏移是：

```text
i * cols + j
```

若每个元素占 `w` 字节、首地址为 `base`，地址为 `base + (i * cols + j) * w`。

**[注意]** 公式中的行列下标从 0 开始。教材若以下界 `L1`、`L2` 表示，需要先减去对应下界。

## 2. 特殊矩阵压缩

- 对称矩阵：只存上三角或下三角，空间从 O(n²) 降为 O(n²/2)。
- 三角矩阵：存一侧三角区域和一个公共常量。
- 对角/带状矩阵：只保存主对角线附近元素。
- 稀疏矩阵：非零元素远少于总元素时，保存非零项的位置和值。

## 3. 三元组表

每个非零元素记录 `(row, col, value)`。若按行、列有序，访问单个位置仍可能需要 O(t)，其中 `t` 是非零元素数，但遍历和转置只需处理非零项。

普通转置逐列寻找三元组，复杂度 O(cols × t)。快速转置先统计每列非零元素数并计算新表起始位置，可达 O(cols + t)。

**[边界]** 添加元素时要检查下标；值为 0 不应进入三元组表；重复坐标必须定义为覆盖、累加或拒绝。

## 4. 广义表

广义表是元素可以为原子或另一个广义表的有限序列。例如：

```text
L = (a, (b, c), ())
```

- 长度：最外层元素个数，此例为 3。
- 深度：括号嵌套的最大层数；不同教材对空表深度定义可能不同。
- 表头：第一个元素；表尾：删除表头后剩余元素组成的表，仍是一个表。

**[注意]** 表尾不是“最后一个元素”。这是常见概念题。

## 5. 练习

1. 推导下三角矩阵按行压缩时 `(i,j)` 的下标公式。
2. 手工完成一个 4×5 稀疏矩阵的快速转置。
3. 写出广义表 `((a,b),c,(d,(e)))` 的长度和深度。

**[拓展]** 工程中的稀疏矩阵常用 CSR/CSC 格式；图邻接表可视为稀疏结构的一种应用。
