# 03 Linked List

## 学习目标

- 理解链表的非连续存储。
- 掌握单链表的插入、删除、查找。
- 熟悉虚拟头节点、快慢指针、反转链表。

## 核心概念

链表由节点组成，每个节点保存数据和指向下一个节点的指针。

| 操作 | 复杂度 |
|---|---|
| 已知节点后插入 | O(1) |
| 删除已知后继节点 | O(1) |
| 查找某个值 | O(n) |
| 按下标访问 | O(n) |

## 常见技巧

- 虚拟头节点：简化删除头节点的情况。
- 快慢指针：找中点、判断环。
- 三指针反转：`prev`、`cur`、`next`。

## 易错点

- 删除节点后忘记释放内存。
- 改指针顺序错，导致链断开。
- 空链表、单节点链表没有单独考虑。

## 典型题型

- 反转链表。
- 合并两个有序链表。
- 删除倒数第 N 个节点。
- 判断链表是否有环。

## 掌握标准

- 能不看资料写出链表反转。
- 能画出插入和删除时指针变化。
- 能解释链表和数组的优缺点。
