# 03 链表

链表用节点保存数据和链接，节点不必连续。它牺牲随机访问和缓存局部性，换取已知位置附近 O(1) 的链接修改。

## 1. 单链表

节点保存 `value` 和 `next`。访问第 i 个节点必须从头沿指针走，复杂度 O(n)。已知前驱时插入、删除为 O(1)；若需要先查找前驱，总体仍为 O(n)。

**[注意]** “链表插入删除 O(1)”隐含已获得操作位置或前驱，不包括查找时间。

## 2. 哨兵头节点

不存业务数据的 dummy head 使第一个真实节点也有前驱，从而统一头部插入和删除逻辑。空表表现为 `dummy->next == nullptr`。

## 3. 指针修改顺序

删除前先保存目标地址和后继，再断链并释放。反转时保存 `next` 后才能执行 `current->next = previous`，否则剩余链表地址会丢失。

```text
next = current->next
current->next = previous
previous = current
current = next
```

## 4. 双向与循环链表

- 双向链表增加 `prev`，可 O(1) 删除已知节点和反向遍历，但修改时要维护更多链接。
- 循环链表尾节点指回头节点，适合轮转问题；遍历终止条件不能再写 `p != nullptr`。
- 双向循环链表配合哨兵可统一大量边界情况，`std::list` 的思想与此相近。

## 5. 所有权与复制

每个节点由链表唯一拥有。析构必须遍历释放全部节点。配套基础示例禁止复制，防止默认浅拷贝；若要支持复制，必须逐节点创建新链，即深拷贝。

**[工程实践]** 也可用 `std::unique_ptr<Node>` 表示 next 的独占所有权，从类型上避免泄漏；反向 `prev` 通常使用非拥有裸指针。

## 6. 高频技巧

- 快慢指针：找中点、判环。
- Floyd 判环：慢指针一步、快指针两步，相遇则有环。
- 虚拟头节点：统一删除头节点。
- 三指针反转。
- 合并有序链表：每次接入较小节点。

**[边界]** 必测空链表、单节点、删除头尾、不存在值、全部删除、偶数/奇数长度和有环输入。

## 7. 练习

1. 为基础实现维护尾指针，使尾插 O(1)。反转后如何更新尾指针？
2. 实现双向链表并列出每次插入要修改的四条链接。
3. 证明快慢指针为什么能检测环。
4. 实现删除倒数第 k 个节点，处理 k 非法的情况。

**[拓展]** 跳表在多层有序链表上建立索引，平均 O(log n) 查找，是概率型数据结构。
