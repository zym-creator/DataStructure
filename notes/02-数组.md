# 02 Array

## 学习目标

- 理解数组的连续存储特性。
- 掌握访问、插入、删除、查找的复杂度。
- 会使用 `std::vector`，也能手写简单动态数组。

## 核心概念

数组在内存中连续存储，所以可以通过下标快速访问元素。

| 操作 | 复杂度 |
|---|---|
| 按下标访问 | O(1) |
| 尾部插入 | 均摊 O(1) |
| 中间插入 | O(n) |
| 中间删除 | O(n) |
| 顺序查找 | O(n) |

## C++ 常用工具

```cpp
vector<int> nums;
nums.push_back(10);
nums.pop_back();
nums.size();
nums[0];
```

## 易错点

- 下标越界。
- 插入和删除时元素移动方向写反。
- `vector.size()` 返回的是无符号类型，倒序循环要小心。

## 典型题型

- 双指针。
- 前缀和。
- 滑动窗口。
- 原地删除元素。

## 掌握标准

- 能手写简单动态数组。
- 能说出数组为什么支持 O(1) 随机访问。
- 能解释为什么中间插入和删除是 O(n)。
