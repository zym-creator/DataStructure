# 02 数组与顺序表

## 1. 逻辑结构与存储结构

线性表是具有相同类型的有限序列。顺序表用一段连续内存保存线性表，数组是它的直接实现。

连续存储使地址可由 `base + index × sizeof(T)` 算出，因此随机访问 O(1)，也具有良好的缓存局部性。

| 操作 | 时间复杂度 |
|---|---|
| 按下标访问 | O(1) |
| 按值顺序查找 | O(n) |
| 尾插（有空间） | O(1) |
| 尾插（动态数组均摊） | O(1) |
| 任意位置插入/删除 | O(n) |

## 2. 插入与删除

在位置 i 插入前，元素 `[i,size)` 必须从后向前移动，否则尚未复制的值会被覆盖。删除后则从前向后移动 `[i+1,size)`。

**[边界]** 插入允许 `index == size`（尾插）；访问和删除只允许 `index < size`。空数组不能访问或删除。

## 3. 动态扩容

容量不足时申请更大空间、搬移元素、释放旧空间。若每次只增加 1，总搬移成本为 `1+2+...+n=O(n²)`；倍增容量可让 n 次尾插总成本 O(n)。

`size` 是当前元素数，`capacity` 是无需重新分配可容纳的元素数，二者不能混用。

## 4. 深拷贝与移动

配套 `DynamicArray<T>` 拥有动态数组，因此实现了析构、深拷贝和移动。默认浅拷贝只复制地址，会造成对象互相影响和重复释放。完整原理见 00 章。

**[注意]** 手写模板中的 `new T[n]` 要求 T 可默认构造，这比真正的 `std::vector` 限制更强。教学实现不等于标准库的完整替代品。

## 5. `std::vector`

```cpp
std::vector<int> values;
values.push_back(10);
values.insert(values.begin(), 5);
values.erase(values.begin());
```

- `operator[]` 不检查越界；`at()` 越界抛异常。
- 扩容会使指向元素的指针、引用和迭代器失效。
- `reserve(n)` 只改变容量；`resize(n)` 改变元素数量。

**[工程实践]** 实际代码优先使用 `std::vector`。手写动态数组是为了理解连续存储、扩容和资源所有权。

## 6. 常见应用

双指针、滑动窗口、前缀和、差分和二分查找都依赖数组的随机访问。前缀和用 O(n) 预处理换取 O(1) 区间和查询。
