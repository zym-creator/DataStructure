# 05 Queue

## 学习目标

- 理解先进先出 FIFO。
- 会手写循环队列，也会使用 `std::queue`。
- 掌握 BFS 的基础队列模型。

## 核心概念

队列从队尾插入，从队头删除。

| 操作 | 复杂度 |
|---|---|
| 入队 push | O(1) |
| 出队 pop | O(1) |
| 查看队头 front | O(1) |

## C++ 常用工具

```cpp
queue<int> q;
q.push(1);
q.front();
q.pop();
q.empty();
```

## 典型题型

- 层序遍历。
- BFS 最短步数。
- 滑动窗口。
- 任务调度。

## 易错点

- `pop()` 不返回元素。
- 循环队列要处理空和满的判断。
- BFS 要在入队时标记访问，避免重复入队。

## 掌握标准

- 能手写循环队列。
- 能解释队列和栈的区别。
- 能写出 BFS 的基本框架。
