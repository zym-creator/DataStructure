# 05 队列

队列从队尾入队、从队头出队，遵循先进先出（FIFO）。基本操作 `push/back`、`pop/front`、`empty` 均应为 O(1)。

## 1. 循环队列

若数组队列只让 front/rear 单调前进，出队后的空间会浪费。循环队列令下标按容量取模回到开头。

本项目使用 `count` 记录元素个数，因此：

```text
empty: count == 0
full : count == capacity
front: data[frontIndex]
```

另一种经典方案浪费一个槽位，用 `(rear + 1) % capacity == front` 判满。两套方案不能混用。

**[边界]** 容量必须大于 0；满队列继续入队和空队列出队应抛出异常或返回失败，不能静默覆盖数据。

## 2. 链队列

用单链表保存元素并维护 front、rear 指针。入队挂到 rear，出队移除 front。最后一个元素出队后必须把 rear 也置空，否则 rear 会成为悬空指针。

## 3. 双端队列与优先队列

双端队列允许两端插入删除，C++ 对应 `std::deque`。滑动窗口最大值通常使用单调双端队列，而不是普通队列。

优先队列每次取最大/最小优先级元素，不保证先进先出；通常由堆实现，入队和出队 O(log n)。

## 4. BFS

BFS 用队列按层访问图或网格。无权图从源点出发时，第一次访问某节点的层数就是最短边数。必须在入队时标记访问，避免重复入队。

## 5. 练习

1. 模拟容量 3 的循环队列：入队、出队、回绕、满和空。
2. 实现链队列并处理从一个元素变空的情况。
3. 用 BFS 求迷宫最短步数，并记录前驱恢复路径。
4. 解释普通队列为什么不能直接解决滑动窗口最大值。

**[拓展]** 生产者-消费者队列涉及互斥、条件变量和内存可见性，属于并发编程，不应把普通队列直接当线程安全容器使用。
