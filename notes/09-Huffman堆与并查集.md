# 09 Huffman 树、堆与并查集

## 1. Huffman 树

带权路径长度 WPL 是所有叶节点“权值 × 根到叶路径长度”之和。Huffman 树是在给定叶权值下 WPL 最小的二叉树。

构造方法：

1. 每个权值建立一棵单节点树。
2. 反复取权值最小的两棵树合并，新根权值为二者之和。
3. 直到只剩一棵树。

使用最小堆后复杂度为 O(n log n)。

Huffman 编码规定左边为 0、右边为 1（反过来也可以），叶节点路径形成编码。它是前缀编码：任何字符编码都不是另一个字符编码的前缀，因此可以无歧义解码。

**[注意]** 权值相同时树形和具体编码可能不唯一，但最小 WPL 相同。只有一个字符时通常给它编码 `0`，否则空编码不便传输。

## 2. 二叉堆

堆是满足堆序性的完全二叉树：

- 最小堆：父节点不大于孩子，根是最小值。
- 最大堆：父节点不小于孩子，根是最大值。

数组下标关系见树章节。插入时把元素放在末尾并向上调整；删除根时用末尾元素覆盖根，再向下调整。

| 操作 | 复杂度 |
|---|---|
| 查看根 | O(1) |
| 插入 | O(log n) |
| 删除根 | O(log n) |
| 自底向上建堆 | O(n) |

**[注意]** 堆只保证父子关系，不保证整个数组有序。查找任意值仍是 O(n)。

## 3. 并查集

并查集维护互不相交的集合，支持：

- `find(x)`：找到 x 所属集合代表。
- `unite(a,b)`：合并两个集合。
- `connected(a,b)`：判断是否属于同一集合。

两项关键优化：

- 路径压缩：查找后让路径节点直接指向根。
- 按大小/秩合并：小树挂到大树下。

同时使用时，m 次操作的均摊复杂度近似 O(m)，严格写作 O(m α(n))，α 是增长极慢的反 Ackermann 函数。

**[拓展]** 并查集用于 Kruskal 最小生成树、动态连通性；普通并查集不支持高效删除边和撤销，回滚并查集属于进阶内容。
