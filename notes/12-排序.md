# 12 内部排序

排序使记录按关键字有序。内部排序指数据可全部放入内存；外部排序需要借助外存。

## 1. 评价指标

- 时间复杂度：最好、平均、最坏情况。
- 空间复杂度：是否原地排序。
- 稳定性：相等关键字记录排序后相对次序是否保持。
- 适应性：输入已有部分顺序时能否更快。

**[注意]** 稳定性针对含附属信息的记录才有意义；仅观察整数值看不出相等元素是否换序。

## 2. 比较表

| 算法 | 最好 | 平均/最坏 | 额外空间 | 稳定 |
|---|---:|---:|---:|---|
| 直接插入 | O(n) | O(n²) | O(1) | 是 |
| 希尔 | 依增量 | 常低于 O(n²)，最坏依增量 | O(1) | 否 |
| 冒泡 | O(n) | O(n²) | O(1) | 是 |
| 快速 | O(n log n) | 平均 O(n log n)，最坏 O(n²) | 平均 O(log n) | 否 |
| 简单选择 | O(n²) | O(n²) | O(1) | 否 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 否 |
| 归并 | O(n log n) | O(n log n) | O(n) | 是 |

## 3. 插入类

直接插入排序维护有序前缀，把当前元素向左插入正确位置。小规模或近乎有序时表现很好。

希尔排序按增量把元素分组进行插入排序，逐步缩小增量直到 1。它打破相等元素相对次序，因此不稳定。

## 4. 交换类

冒泡排序反复交换相邻逆序对。一趟没有交换即可提前结束。

快速排序选枢轴并划分小于、等于、大于区域，再递归处理两侧。避免最坏情况的常用手段包括随机枢轴、三数取中和三路划分。

**[注意]** 快排划分边界最易出错。先固定一种区间约定，并用空区间、二元素、全相等和已有序数组验证。

## 5. 选择类

简单选择排序每轮选择最小元素放到前面，交换次数少但比较始终 O(n²)。

堆排序建立最大堆，将根与末尾交换，缩小堆并向下调整。建堆应从最后一个非叶节点向前调整，整体 O(n)，不是 O(n log n)。

## 6. 归并排序

把序列递归分半，分别排序后合并。合并时相等元素优先取左侧即可保持稳定。适合链表和外部排序，但数组版需要 O(n) 辅助空间。

递归式 `T(n)=2T(n/2)+O(n)`，所以是 O(n log n)。

## 7. 非比较排序

- 计数排序：键范围较小时统计次数，O(n+k)。
- 桶排序：依赖数据分布。
- 基数排序：按个位、十位等逐位稳定排序。

比较排序在一般模型下存在 Ω(n log n) 下界；非比较排序利用键的额外结构，因此不矛盾。

## 8. 外部排序

数据大于内存时，先生成多个有序归并段，再进行多路归并。败者树用于高效选择多路中的最小记录；置换选择可生成更长初始归并段。

**[拓展]** 实际库排序常为混合算法：`std::sort` 通常采用 introsort 思想，在快排递归过深时转堆排序，小区间转插入排序。

## 9. 练习

1. 对同一序列手算每种算法第一趟结果。
2. 给记录附加原始编号，验证算法稳定性。
3. 构造让固定首元素快排达到 O(n²) 的输入。
4. 解释为什么合并两个有序序列是 O(n)。
