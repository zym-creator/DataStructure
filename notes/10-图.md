# 10 图

## 1. 基本概念

图 `G=(V,E)` 由顶点集和边集组成。

- 无向图的边无方向，顶点度数之和等于 `2|E|`。
- 有向图区分入度和出度，所有入度之和与所有出度之和都等于 `|E|`。
- 路径长度可指边数；带权图中也可指权值和，必须看题目定义。
- 连通图任意两点可达；有向图还区分强连通。
- 简单路径不重复顶点；简单图通常没有自环和重边。

**[注意]** “有路径”与“有边”不同；有向边 `(u,v)` 不代表 `(v,u)`。

## 2. 存储结构

### 邻接矩阵

`matrix[u][v]` 表示是否有边或边权。

- 空间 O(V²)。
- 判断一条边 O(1)。
- 枚举一个顶点邻边 O(V)。
- 适合稠密图。

### 邻接表

每个顶点保存出边列表。

- 空间 O(V+E)。
- 枚举邻边 O(deg(v))。
- 适合稀疏图，是算法题常用表示。

无向边在邻接表中通常存两次。统计空间或遍历时不要误认为是两条不同的边。

## 3. DFS 与 BFS

DFS 沿一条路径深入再回溯，使用递归或栈；BFS 按距离层次扩展，使用队列。

邻接表下二者复杂度都是 O(V+E)，邻接矩阵下为 O(V²)。若图不连通，要从每个尚未访问的顶点重新启动，得到 DFS/BFS 森林。

**[注意]** BFS 应在**入队时**标记访问，否则同一节点可能被多次入队。DFS 递归要关注深图导致的调用栈溢出。

## 4. 最小生成树 MST

连通无向带权图的生成树包含全部 V 个顶点和 V-1 条边。MST 使总权值最小。

- Prim：从一个顶点集合向外选择最小跨边；适合稠密图，堆优化后也适合稀疏图。
- Kruskal：边按权排序，依次加入不会成环的边；用并查集判环，复杂度 O(E log E)。

**[注意]** MST 只针对无向连通图。边权相同可能有多棵 MST，但最小总权值相同。

## 5. 最短路径

### Dijkstra

适用于**边权非负**的单源最短路。每次确定当前距离最小的未确定顶点，并松弛它的出边。邻接表加最小堆复杂度 O((V+E)log V)。

松弛：若 `dist[u] + w(u,v) < dist[v]`，更新 `dist[v]` 和前驱。

**[注意]** 只要存在可达负权边，就不能直接使用 Dijkstra。负权可用 Bellman-Ford；所有点对可用 Floyd-Warshall（O(V³)）。负环可使最短路径没有有限答案。

## 6. DAG、拓扑排序与关键路径

有向无环图称 DAG。拓扑序保证每条边的起点都出现在终点之前。

Kahn 算法：把所有入度 0 顶点入队，反复取出并删除其出边。若最终输出顶点数小于 V，图中有环。复杂度 O(V+E)。

拓扑序可能不唯一。若每一步入度 0 顶点都只有一个，才可据此判断唯一。

AOE 网以边表示活动，通过事件最早/最迟发生时间求关键活动。关键路径上的活动延误会直接延误工期。

## 7. 练习

1. 分别画同一图的邻接矩阵和邻接表。
2. 从指定顶点手算 DFS、BFS；邻接点访问次序不同可能得到不同合法结果。
3. 用 Prim 和 Kruskal 求同一张图的 MST。
4. 手算 Dijkstra 的 `dist` 和 `visited` 每轮变化。
5. 对 DAG 写出全部可能拓扑序。

**[拓展]** 强连通分量可学 Tarjan/Kosaraju；网络流、二分图匹配和 A* 通常属于算法进阶。
