# 11 查找

查找表是同一类型记录的集合，关键字用于区分记录。平均查找长度 ASL 是查找过程中关键字比较次数的期望值。

## 1. 顺序查找

从头逐项比较，无需数据有序，时间 O(n)，空间 O(1)。若各记录查找概率不同，把高频记录放前面可以降低 ASL。

“哨兵”技巧把目标临时放在边界位置，循环内可少做一次越界判断。现代代码应优先保证接口清晰，不必为了微小常数牺牲安全。

## 2. 折半查找

前提：数据有序且支持随机访问。每次与中点比较并排除一半区间，时间 O(log n)。链表即使有序也不适合折半，因为访问中点需要 O(n)。

常用左闭右开区间 `[left,right)`：

```text
while left < right
mid = left + (right-left)/2
```

查找第一个“不小于 target”的位置称 `lower_bound`。它比“找到任意相等元素”更通用，还可与 `upper_bound` 组合统计重复元素。

**[注意]** 循环条件、区间定义和边界更新必须一致；混用闭区间公式是死循环和漏查的主要来源。

## 3. 二叉搜索树 BST

对每个节点，左子树键小于节点，右子树键大于节点（重复键如何处理需另行约定）。中序遍历得到有序序列。

- 平均查找/插入/删除 O(log n)。
- 最坏退化成链表，O(n)。

删除分三种情况：叶节点直接删；只有一个孩子时用孩子替代；两个孩子时用中序后继或前驱替代，再删除该节点。

## 4. AVL 树

AVL 是任意节点左右子树高度差绝对值不超过 1 的 BST。插入后从下向上更新高度，失衡分四类：

- LL：右旋。
- RR：左旋。
- LR：先对左孩子左旋，再对节点右旋。
- RL：先对右孩子右旋，再对节点左旋。

AVL 高度 O(log n)，因而查找、插入、删除均为 O(log n)。

**[注意]** “LL”描述新节点落在失衡节点左孩子的左侧，不是旋转方向。

## 5. 散列表

散列函数把关键字映射到桶下标。冲突指不同关键字映射到同一位置，无法完全避免。

常见处理：

- 拉链法：每个桶保存链表/动态数组。
- 开放寻址：冲突后按探测序列寻找空槽，包括线性探测、二次探测、双重散列。

装载因子 `α = 元素数 / 桶数`。α 越高，冲突通常越多；扩容时必须重新散列，因为桶数改变后下标改变。

平均查找接近 O(1)，最坏 O(n)。这不是有序结构，不能高效完成范围查询。

**[注意]** 开放寻址删除不能简单改为空，否则会截断后续探测链；需要“已删除”标记或重新整理。

## 6. 分块与多路查找

分块查找先查索引块，再在块内顺序查找。静态索引可在速度与维护成本间折中。

**[拓展]** B 树和 B+ 树通过高分支降低外存访问次数。B+ 树数据集中在叶层且叶节点相连，适合数据库范围扫描。红黑树比 AVL 放宽平衡条件，更新通常更少，是许多有序容器的实现选择。
