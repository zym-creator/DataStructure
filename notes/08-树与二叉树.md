# 08 树与二叉树

## 1. 基本术语

树是 n 个节点的有限集合。n=0 时为空树；非空时有且仅有一个根，其余节点分成互不相交的子树。

- 节点的度：孩子数；树的度：所有节点度的最大值。
- 叶节点：度为 0 的节点。
- 深度：从根向下计算的层次；高度：从叶向上计算的最长路径。不同教材可能从 0 或 1 开始计数。
- 森林：若干棵互不相交树的集合。

**[注意]** 回答高度/深度数值题前先说明根是第 0 层还是第 1 层。本项目约定空树高度为 0，单节点树高度为 1。

## 2. 二叉树性质

二叉树每个节点最多有左右两个孩子，左右次序不能交换。

- 第 i 层最多 `2^(i-1)` 个节点（根为第 1 层）。
- 高度为 h 的二叉树最多 `2^h - 1` 个节点。
- 任意非空二叉树中，度为 0 的节点数 `n0 = n2 + 1`。
- 含 n 个节点的完全二叉树高度为 `floor(log2(n)) + 1`。

满二叉树每层节点都达到最大；完全二叉树只允许最后一层从右侧缺失。二者不能混淆。

## 3. 顺序与链式存储

完全二叉树适合数组。使用 0 下标时，节点 i 的：

```text
左孩子 2i+1，右孩子 2i+2，父节点 (i-1)/2
```

一般二叉树用左右孩子指针存储更节省空间。

## 4. 遍历

- 先序：根、左、右。适合复制、序列化结构。
- 中序：左、根、右。BST 的中序结果有序。
- 后序：左、右、根。适合删除子树、计算目录大小。
- 层序：逐层访问，需要队列。

递归遍历代码短，本质上使用调用栈。非递归中序遍历显式维护栈：一路压入左链，弹出访问，再转向右子树。

遍历时间均为 O(n)，递归或显式辅助空间最坏 O(h)。斜树 h=n，平衡树 h=log n。

## 5. 由遍历序列还原

- 先序 + 中序：可以唯一确定没有重复标识的二叉树。
- 后序 + 中序：同样可以。
- 先序 + 后序：一般不能唯一确定。

核心是由先序首元素或后序末元素确定根，再用中序划分左右子树。

**[注意]** 若节点值重复，仅凭值序列不能可靠划分。

## 6. 线索二叉树

普通二叉链表有大量空指针。线索化把空左指针指向遍历前驱、空右指针指向遍历后继，并用标志位区分孩子与线索，从而无需栈遍历。

**[注意]** 线索化依赖遍历次序；中序线索不能直接当作先序线索使用。

## 7. 树、森林与二叉树转换

“左孩子、右兄弟”表示法：节点左指针指向第一个孩子，右指针指向下一个兄弟。由此可将任意树或森林转换为二叉树。

## 8. 练习

1. 证明 `n0 = n2 + 1`。
2. 分别手写递归和非递归中序遍历。
3. 根据先序 `ABDECFG`、中序 `DBEAFCG` 画树并写后序。
4. 写函数判断两棵树结构和值是否相同。
