# 04 Stack

## 学习目标

- 理解后进先出 LIFO。
- 会手写栈，也会使用 `std::stack`。
- 掌握括号匹配、表达式处理、单调栈入门。

## 核心概念

栈只允许在一端进行插入和删除。

| 操作 | 复杂度 |
|---|---|
| 入栈 push | O(1) |
| 出栈 pop | O(1) |
| 查看栈顶 top | O(1) |

## C++ 常用工具

```cpp
stack<int> st;
st.push(1);
st.top();
st.pop();
st.empty();
```

## 典型题型

- 有效括号。
- 逆波兰表达式。
- 浏览器前进后退。
- 每日温度、下一个更大元素。

## 易错点

- `pop()` 不返回元素，需要先 `top()` 再 `pop()`。
- 调用 `top()` 前必须确认栈非空。
- 单调栈里要明确维护递增还是递减。

## 掌握标准

- 能手写数组栈。
- 能用栈解决括号匹配。
- 能解释栈为什么适合处理“最近未匹配”的问题。
