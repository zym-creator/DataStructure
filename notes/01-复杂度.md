# 01 算法与复杂度

## 1. 什么是算法

算法是解决一类问题的有限步骤。通常要求有输入、输出、确定性、有限性和可行性。评价算法既看正确性，也看时间、空间、可读性和鲁棒性。

数据结构描述数据之间的逻辑关系、存储方式及其操作；算法描述如何处理这些数据。二者不可分割。

## 2. 输入规模与基本操作

复杂度不是某台电脑上的秒数，而是输入规模 n 增长时资源消耗的趋势。分析时选取执行次数能代表总工作量的基本操作，例如搜索中的关键字比较。

## 3. 渐进记号

- `O(g(n))`：渐进上界，增长不会比 g 更快一个数量级。
- `Ω(g(n))`：渐进下界。
- `Θ(g(n))`：紧确界，上下界同阶。

课程中口头说“复杂度是 O(n)”常意指紧确阶，但严格表达应区分 O 与 Θ。

```text
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2^n) < O(n!)
```

忽略常数和低阶项：`3n² + 2n + 8 = Θ(n²)`。对数底数仅相差常数，所以通常写 `log n`。

## 4. 常见分析

顺序语句复杂度相加，保留最高阶；嵌套循环通常相乘，但循环上下界相关时应计算求和。

```cpp
for (int i = 1; i <= n; i *= 2) {} // Θ(log n)

for (int i = 0; i < n; ++i)
    for (int j = 0; j < i; ++j) {} // 0+1+...+(n-1)=Θ(n²)
```

**[注意]** 不能仅看到两层循环就断定 O(n²)。若内层变量在整个过程中只前进 n 次（双指针），总复杂度可能是 O(n)。

## 5. 最好、平均与最坏

顺序查找首元素最好 Θ(1)，末元素或不存在最坏 Θ(n)。平均复杂度依赖输入概率模型。未注明时，算法题通常要求最坏复杂度；必须结合语境。

## 6. 递归复杂度

写出递推式，再观察每层工作量和递归深度：

- 二分查找：`T(n)=T(n/2)+Θ(1)=Θ(log n)`。
- 归并排序：`T(n)=2T(n/2)+Θ(n)=Θ(n log n)`。
- 朴素 Fibonacci：重复子问题导致指数级时间。

递归空间还包括调用栈。尾递归在 C++ 中不保证被优化。

**[拓展]** 主定理可快速分析 `T(n)=aT(n/b)+f(n)`，但不适用于所有递推式。

## 7. 均摊分析

动态数组单次扩容需要 O(n)，但容量按倍数增长时，连续 n 次尾插的总搬移量是几何级数 O(n)，所以每次尾插均摊 O(1)。均摊不是概率平均，而是对一串操作总成本的保证。

## 8. 空间复杂度

通常分析额外空间：输入本身不计入。原地算法一般指额外空间 O(1)。递归深度、临时数组和容器容量都要计入。

## 9. 最大子列和案例

配套代码给出 O(n³)、O(n²)、前缀和、分治 O(n log n) 和 Kadane O(n) 五种方法，用同一问题观察优化过程。

**[注意]** 示例约定允许空子列，因此全负数组结果为 0。若题目要求非空子数组，应将初值设为首元素并调整转移。
