# 01 Complexity

## 学习目标

- 理解时间复杂度和空间复杂度的含义。
- 能判断常见代码片段的复杂度。
- 能比较 O(1)、O(log n)、O(n)、O(n log n)、O(n^2) 的增长速度。

## 核心概念

复杂度描述的是输入规模变大时，程序运行时间或内存占用的增长趋势。

常见复杂度从低到高：

```text
O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(2^n)
```

## 常见例子

```cpp
// O(1)
int x = a[0];

// O(n)
for (int i = 0; i < n; i++) {}

// O(n^2)
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {}
}

// O(log n)
while (n > 1) {
    n /= 2;
}
```

## 判断方法

- 看循环执行次数。
- 看递归分裂规模。
- 忽略常数项，例如 O(2n) 写作 O(n)。
- 保留最高阶项，例如 O(n^2 + n) 写作 O(n^2)。

## 练习

- 写出顺序查找的复杂度。
- 写出二分查找的复杂度。
- 写出双重循环枚举所有数对的复杂度。
- 分析 `std::vector` 尾部插入和中间插入的复杂度。

## 掌握标准

- 能看代码判断大致复杂度。
- 能解释为什么二分查找是 O(log n)。
- 能区分时间复杂度和空间复杂度。
